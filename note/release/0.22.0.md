# Papo 0.22.0 发布说明

- 基线：Minecraft 1.21.11 / Paper 上游（分支 ver/1.21.11）
- 产物：`paper-server/build/libs/Papo-1.21.11-0.22.0.jar`
- 红线保持：行为等价（全部改动经事件 HandlerList 层级 / CraftItemStack round-trip 引理 / 逐位等价论证），完整 test 套件 + applyPatches 全绿（915+6 patches）
- **游戏版本红线：始终保持 Minecraft 1.21.11**

## 新增优化（0181–0189，共 9 个补丁 + 1 个直接提交）

零监听器事件门控规模化续批 + 网络/会话/世界 tick 分配消除。三个 survey 子代理产出 19 候选，逐个代码复核后落地 10 项；JMH 实测 **8 项正收益（1.17×–18.13×，CI 均不重叠）**：

- **0181 GameEventDispatcher.post BlockPos 消除 + debug 订阅者门控**：每次游戏事件派发省 1 BlockPos（**2.27×**）
- **0182 熔炉三事件门控**（FurnaceBurn **5.97×** / FurnaceStartSmelt **18.13×** / FurnaceSmelt **3.25×**）：熔炉阵列高频路径省镜像+CraftBlock+事件+空派发
- **0183 营火 BlockCookEvent 门控**（**1.73×**）：门控单次 copy 保证 split 循环不就地改槽
- **0184 VaultDisplayItemEvent 门控**（**15.18×**）：宝库展示轮换事件路径完全消除
- **0185 PlayerArmSwingEvent 门控**（**6.32×**）：挥臂包（PvP/挖掘最高频包之一）每包省事件构造+空派发
- **0186 ItemStack 编码 withItemStack 直路**：每 ItemStack 编码省捕获 lambda（复刻内中性、EA 伪影判例机制保留；默认非混淆配置调用点仍分配）
- **直接提交 ItemObfuscationSession start 上下文按级缓存**（**1.29×**）：每实体数据/装备包每连接省 1 上下文分配
- **0187 属性快照列表预尺寸**（**2.42×**）：14 属性同步免三次扩容拷贝
- **0188 LivingEntity.baseTick 气泡柱 scratch pos**（**1.17×**）：水下实体每 tick 省 1 BlockPos
- **0189 EntityEffectTickEvent 门控**：药效应用 tick 事件门控（复刻内中性、EA 伪影判例机制保留；真实路径注册表转换成本未被复刻覆盖）

## 撤除记录（0187 记分板部分）

- **ServerScoreboard Optional.empty 改写撤除**：survey 称"每分数变更 2 次 Optional 分配"，复核 JDK 实现证伪——`Optional.ofNullable(null)` 本就返回 empty() 单例，null 分支两写法均零分配（非 EA 伪影，是真零收益纯搅动）。JMH 1.791 vs 1.728 CI 重叠证实中性，按"实测无收益即撤"精神从补丁撤除（手工编辑补丁 → 完整 applyPatches 同步 → 验证链全绿）。**新判例**：survey 候选的"分配"断言需对照 JDK 实现复核，不能凭方法名望文生义（已记入 build.md）
