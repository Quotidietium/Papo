# Papo 0.50.0 发布说明

- 基线：Minecraft 1.21.11 / Paper 上游
- 产物：`paper-server/build/libs/Papo-1.21.11-0.50.0.jar`
- 红线保持：默认行为等价、API 零变更、游戏版本红线 1.21.11 不变
- **游戏版本红线：始终保持 Minecraft 1.21.11**
- 性质：**多玩家网络稳定——实体同步域三项**（批次 76，survey 驱动）

## 新增优化（0247）

### 无观众实体跳过包构造（主项）
刷怪塔/农场等"实体 ticking 但无观众"场景（追踪范围外 mob/item farm），`sendChanges` 此前仍每
周期构造 move/PositionSync/motion/RotateHead/minecart 包后对空 seenBy 广播丢弃。现
`papoHasViewers` 守卫 11 个构造站点**只跳 new**——ServerEntity 内部状态机（发送基准
base/lastSent 系列/teleportDelay/dirty 清除/attributes 清理）逐行保留；AndSelf 站点保留玩家
自收路径。有观众路径逐字节不变。

### seenBy 稳态双探测短路
0204 的 contains 之后 add 内部再探测——稳态每 (实体,玩家) 对每 tick 两次身份哈希探测；
`!papoAlreadyTracked && add` 短路（其间无写入，add 可证 no-op）。

### 矿车路径 Vec3 内联
`positionCodec.delta(vec3).lengthSqr()` 每 gate 一次 Vec3 分配 → 标量内联（主路径 Paper 同款
先例；位级一致自检 10 万点）。

## 基准

- EntitySyncNoViewerBench：无观众包构造 76.295 → **12.215 ns/op（6.2×，CI 分离）**；双探测
  3.563 → **1.916 ns/op（1.86×，CI 分离）**；矿车 Vec3 项复刻内 CI 重叠（EA 伪影判例，机制保留）。
- 外推：500 追踪范围外实体 ≈ 64µs/tick 纯垃圾构造消除 + 10k (实体×玩家) 对 ≈ 16µs/tick。
