- 基线：Minecraft 1.21.11 / Paper 上游（分支 ver/1.21.11）
- 产物：`paper-server/build/libs/Papo-1.21.11-0.29.0.jar`
- 红线保持：行为等价（协议时点完全不变）、API 零变更、游戏版本红线 1.21.11 不变
- **游戏版本红线：始终保持 Minecraft 1.21.11**

## 新增优化（0206）

### 0206 — ServerEntity trackedDataValues 缓存刷新延后到 pairing
- `sendDirtyEntityData` 原 每次 dirty 刷新 `trackedDataValues = getNonDefaultValues()`（全扫实体数据项 + 分配 List），但该字段只在 `sendPairingData`（新观众）被读。稳态聚集（战斗/药水）dirty 频繁、新观众稀少，刷新纯浪费。改为 pairing 时即时计算。
- **协议时点完全不变**：dirty DELTA 包仍由 sendDirtyEntityData 发送；full 快照仍由 sendPairingData 在新观众时发送（仅改即时计算）。与"ServerEntity 增量合并结案"是不同优化。
- **JMH**：per-dirty-tick **2.16× 提速**（62.5 → 28.9 ns/op，CI 不重叠）。
