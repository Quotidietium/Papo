# Papo 0.10.0 发布说明

- 基线：Minecraft 1.21.11 / Paper 上游（分支 ver/1.21.11）
- 产物：`paper-server/build/libs/Papo-1.21.11-0.10.0.jar`
- 红线保持：行为等价（全部改动经逐分支/逐位/字节级等价论证，HandlerList 层级与事件子类全库 grep 实证），完整 test 套件 + applyPatches 全绿（915 patches）
- **游戏版本红线：始终保持 Minecraft 1.21.11**

## 新增优化（0114–0124，共 11 个补丁 + 1 项直接提交）

- **0114 Entity.touchingUnloadedChunk 内联 inflate(1.0) 边界算术**：每实体每 tick 流体检测与每次摔落检查的 AABB 分配消除（2.15×）
- **0115 寻路 getPathType BlockPos 消除**：WalkNodeEvaluator scratch pos 复用（1.66×）+ FlyNodeEvaluator 纯坐标载体折叠（2.80×）
- **0116 漏斗 getEntityContainer AABB 缓存**：suck 侧挂 BE 惰性字段、eject 侧按 searchPosition 键控（6.44×/4.94×），矿车漏斗走原路径
- **0117 BlockFadeEvent 16 调用点零监听器快路**：火熄灭/冰融化/草衰变/积雪融化等 randomTick 路径每次省 CraftBlock+快照+事件+派发
- **0118 玩家状态事件×4 门控**：PlayerToggleSprint/Sneak/ItemHeld/EntityPoseChange（附消除 Pose.values() 每次数组克隆）
- **0119 LeavesDecayEvent/BlockIgniteEvent 门控**：树叶腐烂与火蔓延路径
- **0120 PathNavigation Node 坐标直读**：每寻路生物每 tick 省 2 个 BlockPos（1.80×）
- **0121 EntityPathfindEvent 门控**：每次寻路每目标省 Location+事件+派发
- **0122 矿车事件整块门控**：每矿车每 tick 省 2 Location + 1~2 事件
- **0123 push(x,y,z,null) Vector 消除**：实体-实体挤压每对每 tick（1.13×）
- **0124 EntityTargetEvent 系×3 + EndermanAttackPlayerEvent 门控**：TemptGoal/TemptingSensor/Mob.setTarget/EnderMan
- **直接提交（0125）CraftEventFactory 四事件门控**：新增 handleBlockFadeEvent 快路 + handleBlockSpreadEvent/handleMoistureChangeEvent 零监听器跳事件构造 + callEntityChangeBlockEvent 零监听器早退（覆盖火蔓延/草蔓延/生长湿度/羊吃草/凋零破坏等 35+ NMS 调用点）
