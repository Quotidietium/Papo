# Papo 0.12.0 发布说明

- 基线：Minecraft 1.21.11 / Paper 上游（分支 ver/1.21.11）
- 产物：`paper-server/build/libs/Papo-1.21.11-0.12.0.jar`
- 红线保持：行为等价（全部改动经逐分支/逐位/语义等价论证），完整 test 套件 + applyPatches 全绿（1073 patches：sources 918 + features 149 + resources 6；初版误记 940，以仓库补丁文件计数为准）
- **游戏版本红线：始终保持 Minecraft 1.21.11**

## 新增优化（0134–0149，共 16 个补丁 + 1 项直接提交）

事件门控续批（零监听器短路，监听器存在时路径逐字节保留）：

- **0134 ComponentSerialization 接入 0133 RegistryOps 缓存**：Paper adventure 编解码（聊天 3 包/actionbar/title/TabList/BossBar/实体 CustomName/物品名+lore）与 ByteBufCodecs 同源缓存（机制 10.97×）
- **0137 交互三触发器零监听器早退**：ANY_BLOCK_USE/ITEM_USED_ON_BLOCK/ITEM_USED_ON_AIR 触发前 `papoHasListeners` 短路，stack.copy 随门省略（3.99×）
- **0138 PlayerInteractEvent 零监听器门控 7 调用点**：useItemOn/左键挖掘/mayInteract/右键空气/右键方块/挥臂 raytrace 整段（6.67×；`isCancelled()==useInteractedBlock()==DENY` 逐点语义映射）
- **0139 ResultSlot ItemCraftedEvent 门控×2**：onQuickCraft/onTake 省事件+asBukkitCopy 包装（2.29×）
- **直接提交（0150）callPreCraftEvent 零监听器快路**：每次合成输出刷新省 CraftInventoryCrafting 双包装+mirror+事件+派发

分配消除与循环改写：

- **0135 updateFluidOnEyes 复用实体级 scratch pos**：每实体每 tick 省 1 次 MutableBlockPos（1.29×）
- **0136 POI 查询 Optional 消除**：PoiSection/PoiManager 新增 getTypeOrNull，村庄 POI 竞争扫描免包装拆包（1.50×）
- **0140 handleUseItemOn 命中距离 Vec3×2 展开**：atCenterOf/subtract 分量算术位级等价（含 NaN/Inf 边界矩阵自检；微基准 EA 噪声经 gc 剖析证伪，见报告）
- **0141 PlayerChunkSender 收集两分支命令式**：稳态 else 分支 1.47×；least 分支解析阶段 1.02×（选择算法保持原版）
- **0142 InteractWithDoor scratch + 坐标直读**：每 tick 双 asBlockPos 免分配（1.74×）；门分支逃逸点（GlobalPos/CraftBlock）仍分配 immutable
- **0143 EntityEquipment.tick 遍历 VALUES**：免 EnumMap entrySet 每槽 MapEntry（2.20×；同枚举序）
- **0144 熔炉 SingleRecipeInput 按栈引用缓存**：燃烧中每 tick 省 record 分配（1.56×；shrink 透过缓存可见性自检）
- **0145 ChunkHolder.broadcast 索引循环**：捕获 lambda forEach 改写（复测 CI 重叠持平；players 为局部新建 ArrayList 语义等价）
- **0146 光照更新包两列表按截面数预分配**：免 10→15→22→33 扩容拷贝（2.11×）
- **0147 实体追踪 getEffectiveRange 扫描外提**：每 (实体,玩家) 对→每扫描一次（1.06×）
- **0148 Mob.isSunBurnTick BlockPos 延迟构造**：随机/湿身门拦截路径免分配（1.35×；随机消耗步数不变自检）
- **0149 EnchantmentHelper.tickEffects 展开**：equipment 迭代+访问者 lambda 三层间接改直接循环（CI 重叠持平；迭代序不变）

## 兼容性

- API 零变更；所有门控仅在零监听器时短路，有监听器路径逐字节保留原逻辑
- 0138 逐调用点按构造器参数推导零监听器结果（useItemInHand=DEFAULT、useClickedBlock=clickedBlock==null?DENY:ALLOW），无独立 cancelled 字段语义实证
- 0142 scratch 不入逃逸分支（setOpen/CraftBlock.at/GlobalPos.of 分配点与原版一致）
- 0144 缓存键为栈引用，槽位换引用（燃尽/放入/NBT 加载）必触发重建，无陈旧窗口
- 无新增配置项
