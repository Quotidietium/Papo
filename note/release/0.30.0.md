## 新增优化（0207）

### 0207 — Connection PacketSendAction 消除 delegate lambda + AtomicBoolean→boolean
- `send` 的非 canSendImmediate 分支（突发负载下 queue 非空时）每排队包原分配 3 对象（PacketSendAction + delegate lambda + AtomicBoolean）。改为：PacketSendAction 加 listener/flush 字段 + override accept 直调 sendPacket（免 lambda）；consumed 由 AtomicBoolean 降为 boolean（processQueue 单线程，CAS 非必要）。
- **JMH**：per-queued-packet **2.03× 提速**（5.379 → 2.651 ns/op，CI 不重叠）；每排队包 3 对象→1 对象。
- **等价性**：accept 调用序列逐字一致；tryMarkConsumed/isConsumed 仅在 processQueue（主线程 play / synchronized login，单线程）调用，CAS→boolean 安全。
