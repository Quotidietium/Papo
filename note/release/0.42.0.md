## 新增优化（0235-0237）

### 0235 — 自然刷怪循环 PreCreatureSpawnEvent 零监听器门控（本批主项）
- 刷怪循环最高频事件站点（MONSTER 每 tick 每刷怪 chunk 每通过距离检查的候选）：零监听器时省 Location + 事件 + 空派发。BaseSpawner 0165 同型；事件块不消耗随机，门控不影响刷怪序列。

### 0236 — 物品/XP 球 merge 扫描去分配
- 每次扫描的 EntityTypeTest 匿名类 + ArrayList + 谓词 lambda（物品每 2-40 tick、XP 球每 20 tick；密集农场局部 O(n²)）→ 静态单例 + 惰性复用。**gc 实证 280 B/op/次扫描真分配消除**；删循环体重复 isMergable（fill→loop 间邻体状态不可变的逐句论证）。

### 0237 — despawnRanges 扁平化
- Mob.checkDespawn **每 mob 每 tick**（EAR 之前）的 HashMap.get → 配置 @PostProcess 建 ordinal 数组直索引。JMH 3.75×。
