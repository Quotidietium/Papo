## 新增（批次 103）

### 玩家 doTick 链分解探针（诊断，默认关）
`-Dpapo.tickProfile=1` 时新增 `player.superTick`（实体 tick 链）与
`player.aiStepTouchScan`（接触扫描段）相位。用于聚堆规模下的玩家 tick 地板归因：
实测实体 tick 链占地板 ~70% 且为语义载荷常量和，接触扫描/推挤各 <1us/玩家——
该面在默认行为等价前提下无削减空间。默认关闭，生产零开销。
