# Papo 0.63.0 发布说明

- 基线：Minecraft 1.21.11 / Paper 上游
- 产物：`paper-server/build/libs/Papo-1.21.11-0.63.0.jar`
- 红线保持：默认行为等价（purge 移除决策逐位一致，含配置失效边界）、API 零变更、游戏版本红线不变
- 性质：**多核调度⑰——实体追踪器 purge 扫描复杂度修正**（批次 101）

## 优化（批次 101）

### 追踪器 purge 探测 O(1) 化
大量玩家聚集且持续移动时（出生点、活动服），区块视图集每次变化触发全部追踪器的
purge——每追踪器对每个已配对玩家做线性成员扫描，聚堆下形成每 tick 数百万次比较的
"purge 风暴"。改为按区块内容版本惰性构建共享探测集合（版本号失效，精确等价），
风暴成本降一个数量级（密度模型 JMH 6.0×）；分散常规服务器行为不变。
