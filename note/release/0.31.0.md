## 新增优化（0208）

### 0208 — PacketBundleUnpacker 非 bundle 包免 list::add Consumer
- IO 线程每出站包原 `unbundlePacket(packet, list::add)` 分配一个 Consumer（`list::add` 方法引用捕获局部 list）；非 bundle 包（99%）实际只 `list.add(packet)`。改为：bundle 走 unbundlePacket，非 bundle 直 list.add。
- **JMH**：**1.23× 提速**（4.504 → 3.669 ns/op，CI 不重叠；EA 未消除，收益真实）。
- **等价性**：unbundlePacket 对非 bundle 包走 else==list.add（type()≠bundle type），bundle 走展开；`instanceof BundlePacket` 路由结果逐字一致。
