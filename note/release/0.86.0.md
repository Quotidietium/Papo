## 光照 nibble 紧凑 uniform 表示（重开批144 判例）

- 天空光在高度图以上的全亮节、无光源的方块光节，整节 4096 个 nibble 全为 15
  或 0：原各占一个 2048 字节数组（普查 10,737 个 = 22.0MB，占堆 2.65%——批144
  否决时仅 1.8%，判例前提已双双失效故重开）。现在这类节**两个存储数组均为
  null**，值承载于一对跟随 SWMR 同款纪律的 uniform 字段（写者私有 plain +
  读者 volatile），占堆比例 2.65% → ~0。
- 安全契约：存储字段全私有且所有读写经类方法路由，并发读协议原样；首写围绕
  uniform 值物化（全亮节写一个边缘 nibble 不丢其余 15）；发布时沉降数组自动
  紧缩回 uniform；盘上保存格式与跨版本世界兼容**字节恒等**（保存物化/盘载
  规范化）；全零载荷保留物化形，INIT-with-zero 与 UNINIT 保持引擎可区分。
- 出航前随机差分（200 轮 × 500 操作）抓到两个写者协议洞——uniform 翻转留下的
  dirty+null 中间态上 set()/extrudeLower() 会写穿 null 数组——三处守卫统一为
  "存储缺失即物化"，并入库确定性回归（11 项契约测试全绿）。
- 浸泡两腿实测（12 bot、6,086 vs 6,145 区块配对，门全绿，配对差 0.97% 在界内）：
  堆 817.4 → 801.4MB（**−1.96%**；区块调整后净 ≈ −21.1MB）；普查归因闭合：
  SWMRNibbleArray byte[] **−21.79MB**，均匀数组 **10,836 → 4 个**，非均匀载荷
  每块率不变，long[]/String/容器实例持平（内容面零触碰）。
