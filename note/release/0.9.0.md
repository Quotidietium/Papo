# Papo 0.9.0 发布说明

- 基线：Minecraft 1.21.11 / Paper 上游（分支 ver/1.21.11）
- 产物：`paper-server/build/libs/Papo-1.21.11-0.9.0.jar`
- 红线保持：行为等价（`SUCK_AABB` 共享不可变常量 + `worldPosition` final + AABB 不可变只读，缓存值与逐次计算逐分量相同），完整 test 套件 + applyPatches 全绿

- **0113 HopperBlockEntity 吸取 AABB 实例缓存**：漏斗上方无方块容器时每个搬运周期的 `getSuckAabb().move(...)` 新 AABB 分配消除。`Hopper.SUCK_AABB` 为共享不可变常量（无覆盖，全树实证）、BE 的 `worldPosition` final，缓存挂 BE 实例惰性初始化；矿车漏斗（会移动）保持逐次计算。漏斗密集（物品分类机）服务器的稳定分配源消除
