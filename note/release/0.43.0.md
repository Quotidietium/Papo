- **游戏版本红线：始终保持 Minecraft 1.21.11**
- 性质：**伤害/战斗管线事件门控**（批次 69——本 fork 事件门控此前未覆盖的最大高频集群）

## 新增优化（0238-0240）

### 0238 — 四组战斗事件零监听器门控（本批主项）
| 事件 | 频率 |
|---|---|
| PlayerAttackEntityCooldownResetEvent | 每次玩家近战命中 |
| PrePlayerAttackEntityEvent ×2（attack/stabAttack） | 每次玩家攻击 |
| PlayerVelocityEvent 第二站点（0100 遗漏补齐） | 每次对 hurtMarked 玩家的攻击 |
| PlayerItemDamageEvent + EntityDamageItemEvent | 每击最多 4-5 发（护甲 4 槽+武器） |

零监听器时**每击最多 8 个事件构造 + Craft 包装归零**；各事件自有表无子类（逐文件实证），零监听分支逐字复刻（0100/0165 同型）。

### 0239 — 横扫 DamageSource 副本提出循环
每横扫目标一份 DamageSource.copy → 循环外共享（常量实参值恒等不可变副本）。

### 0240 — EntityDamageEvent 构造器 stream 校验→循环（paper-api 直提交）
全族最高频事件构造器；JMH **2.74×**（CI 不重叠）；异常类型/消息逐字保持。

## 留档（单独立项）

- **EntityDamageEvent 族全量快路**（每伤害实例 ~40-50 对象）：需传值通道重构 + lastDamageCause 惰性物化（插件可从无关事件读 getLastDamageCause——严格等价需保留原始载体）。
- EntityKnockbackEvent 双事件门控（FP 往返复刻）；非生物伤害事件 9 站点门控（与族级共用方案）。
