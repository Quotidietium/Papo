# Papo 0.21.0 发布说明

- 基线：Minecraft 1.21.11 / Paper 上游（分支 ver/1.21.11）
- 产物：`paper-server/build/libs/Papo-1.21.11-0.21.0.jar`
- 红线保持：行为等价（全部改动经逐分支/逐位/语义等价论证），完整 test 套件 + applyPatches 全绿（1104 patches：sources 918 + features 180 + resources 6）
- **游戏版本红线：始终保持 Minecraft 1.21.11**

## 新增优化（0179–0180，共 2 个补丁，实体块内检测路径）

- **0179 checkInsideBlocks AABB 折叠**：`makeBoundingBox(to).deflate(1.0E-5F)` 两构造 → 单构造，每实体每 tick 省 1 个 AABB（**1.61×**，CI 不重叠；deflate(v)==inflate(-v)、`a-(-b)`≡`a+b`、六分量左结合 FP 链逐字、构造器归一化同输入含极小宽度交换边缘，25 组合逐位自检）
- **0180 块内检测位移差 Vec3 内联**：`movement.to().subtract(from)` 逐分量直取，每 movement 省 1 个 Vec3（subtract/lengthSqr/get(axis) 三处读取逐字内联，24 组合含 NaN/±0.0/巨值逐位自检；复刻内中性、EA 伪影判例机制保留）

## 撤销记录（0181）

- **0181 静止回退 Movement 键控缓存**：初测 **0.46×** 回退（缓存命中 6×Double.compare 贵于 2 次 TLAB 分配）；一轮修正（两段式精确比较，命中⟺逐位相同）复测仍 **0.91×**——按批次29先例（实测回退即撤销）回退：内部提交回退、外仓补丁移除、撤销后验证链全绿。基准类留存 benchmark/src/FallbackMovementCacheBench.java 作证据
