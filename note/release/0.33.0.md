# Papo 0.33.0 发布说明

- 基线：Minecraft 1.21.11 / Paper 上游
- 产物：`paper-server/build/libs/Papo-1.21.11-0.33.0.jar`
- 红线保持：默认行为等价（线上字节/包序不变）、API 零变更、游戏版本红线 1.21.11 不变
- **游戏版本红线：始终保持 Minecraft 1.21.11**
- 性质：**网络带宽优化 + 出站编码延时优化**（批次 58，三路 survey 交叉印证）

## 新增优化（0210-0216）

### 带宽（更少冗余出站字节）

| 补丁 | 内容 | 收益 |
|---|---|---|
| 0210 | PlayerTeam 九个 setter 等值门控 | TAB 类插件周期重设同值时不再全网重播 team 参数包（0 包 vs 每轮全体玩家 ×50-150B） |
| 0211 | Objective 四 setter + Scoreboard.numberFormatOverride 等值门控 | 同上（侧边栏插件） |
| 0212 | ServerScoreboard display-slot 同包双发去重 | 双发路径恰好少一个逐字节相同的包 |

- **等值判定护栏**：Component 仅"不同实例但内容相等"才跳过——同实例重设保持广播（NMS 可变组件靠重设刷新的手段不受影响）；布尔/枚举 `==`。
- 行为自检 ScoreboardGateSelfCheck 全场景 ALL OK（等值跳过/真变更一致/同实例 vanilla 奇偶性/末状态一致）。

### 延时（出站编码路径 CPU/分配/尾延迟）

| 补丁 | 内容 | JMH |
|---|---|---|
| 0213 | prepender 帧缓冲精确预分配 | 均值 2.28×，方差 ±1251→±5（池化重分配双峰消失，尾延迟主价值） |
| 0214 | PacketEncoder 按包类尺寸提示 | **1.46×**（32KB 区块包模型，CI 不重叠；跑图/登录突发期区块包收益最大） |
| 0215 | 压缩输出按 DEFLATE **实测**上界分配 | 本机持平（JDK 回退）；生产 Linux 消除 libdeflate"容量翻倍+整输入重压缩"尖峰（不可压 payload 尾延迟） |

- 0215 判例：首版上界公式被基准自检证伪（256KiB 实测膨胀 +86 > 界 +80），实测规律为 **5B/16384B 窗口 + 6B**（64KiB-4MiB 四点吻合），修正为 `n + n/2048 + 32`。

### 正确性（顺带修复，默认行为不变）

| 补丁 | 内容 |
|---|---|
| 0216 | ① 重复 `setupCompression` 时新建压缩器被双双拒收 → 原生上下文泄漏：改为复用活实例；② `misc.compression-level` 配 10-12 在无 native 平台（Windows）登录即断连：IAE 时 clamp 到 [1,9] 重试（合法配置逐字不变） |

## 工程项：0163-0180 垃圾重命名根除（第 4 次复发后）

127 个补丁（0055-0180）的 RFC2047 中文 Subject 头统一改写为与文件名 slug 往返闭合的英文（`note/fix_patch_subjects.py`，字节级只动头部）→ applyPatches 重建内部仓库 → rebuildPatches 验证：**216 个补丁零垃圾名，14 个历史尾杠文件名一次性归一为终态**。此后全量 rebuildPatches 不再需要恢复法。
