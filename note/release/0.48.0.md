# Papo 0.48.0 发布说明

- 基线：Minecraft 1.21.11 / Paper 上游
- 产物：`paper-server/build/libs/Papo-1.21.11-0.48.0.jar`
- 红线保持：默认行为等价、线上字节恒等、API 零变更、游戏版本红线 1.21.11 不变
- **游戏版本红线：始终保持 Minecraft 1.21.11**
- 性质：**多玩家网络稳定——join 静态大包构造缓存 + 双 memo**（批次 74，join 突发域）

## 新增优化（0245）

### recipes 包 join 静态构造缓存（0226 模式）
`ClientboundUpdateRecipesPacket`（~100-300KB 配方同步数据）此前**每 join 重新构造**；现缓存单实例
跨 join 复用。失效信号完备：`RecipeManager.finalizeRecipeLoading` 是同步数据唯一赋值点，其下游
`PlayerList.reloadResources → reloadRecipes` 清缓存（addRecipe/removeRecipe/datapack reload 全经此链）。

### 三族 join 静态包 arm 双 memo（编码 + 压缩）
tags / registry×24 / recipes 的 0226/0245 缓存实例全部挂 `PapoSharedWireMemo`——每 join 出站成本
从"codec 走查 + DEFLATE"降到两次 memcpy。registry mismatched 分支（ViaVersion 全量 NBT）收益最大。

### record → final class（两个包类）
record 不能声明 memo 实例字段；改为同构造形状、同访问器名的 final class（codec 引用不变；
grep 实证全树无 equals/hashCode 消费者）。

## 基准

- JoinPacketMemoBench（1200 配方 × 3 物品栈 × 8 组件词模型，91.7KB / 压缩比 2.02）：

  CI 分离）**；填充路径持平。
- 50 玩家 join 突发外推 ≈ **355ms CPU 消除**（此前集中爆发在 join 窗口）。
