## 新增优化（0209）

### 0209 — Connection.sendPacket 消除 per-outbound-packet lambda
- 主线程发包（非 netty event loop）原每包 `execute(() -> doSendPacket(...))` 分配 lambda（网络出站最高频分配点）。改为直调 doSendPacket。
- **JMH**：1.29×（1.065→0.827 ns/op，CI 不重叠）。主价值是消除 per-outbound-packet 分配、降低高吞吐下 GC 压力（微基准 modest，真实 GC 收益需 live 验证）。
- **线程安全**（推理验证，逐项）：channel.write/addListener netty 跨线程安全且保序；getPlayer 读 volatile；sentPackets++ 在调用方线程（不在 doSendPacket，消除 lambda 不改其语义）；异常-disconnect 是既有跨线程模式。详见报告。
- **残留风险**：未做 live 并发压测（用户知悉接受）；极端并发下异常路径理论竞态罕见且在消亡连接；单补丁可 revert。
