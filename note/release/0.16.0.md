# Papo 0.16.0 发布说明

- 基线：Minecraft 1.21.11 / Paper 上游（分支 ver/1.21.11）
- 产物：`paper-server/build/libs/Papo-1.21.11-0.16.0.jar`
- 红线保持：行为等价（全部改动经逐分支/逐位/语义等价论证），完整 test 套件 + applyPatches 全绿（1089 patches：sources 918 + features 165 + resources 6）
- **游戏版本红线：始终保持 Minecraft 1.21.11**

## 新增优化（0163–0165，共 3 个补丁，潮涌核心 + 刷怪笼）

- **0163 潮涌核心 updateShape 框架扫描 scratch pos**：每 40 tick 每潮涌核心省内层 3×3×3 水判定 27 次 BlockPos 分配与外层扫描非命中位置分配（scratch 纯坐标读取无逃逸，仅命中框架方块时新建不可变实例入表；JMH 复刻内 EA 抹平 before 分配，gc 剖析两路径 alloc.norm 同为 2016.005 B/op 实证假象，机制性收益保留）
- **0164 潮涌核心两处 AABB 折叠**：applyEffects 效果范围（每 40 tick 激活时）三次分配折叠为一次（**1.61×**）；getDestroyRangeAABB 两次折叠为一次（**1.57×**）。x/y/z/i/h 全为 int，折叠式 int 求和后一次拓宽，doubleToRawLongBits 逐位相等
- **0165 刷怪笼 PreSpawnerSpawnEvent 零监听器快路**：每次刷怪尝试每实体省 2 个 Location + 事件对象分配与空派发（**54.6×**；事件路径完全消除）。PreSpawnerSpawnEvent 无独立 HandlerList，共享 PreCreatureSpawnEvent 静态表，零监听器时 callEvent 恒 true 且无副作用，整体跳过等价

## 基准测试

- JMH 对比报告：[note/report/perf/2026-08-01-jmh-microbench-batch40.md](../report/perf/2026-08-01-jmh-microbench-batch40.md)
- 4 项测量：3 项正收益（1.61×/1.57×/54.6×，CI 不重叠），1 项复刻内中性（0163，经 `-prof gc` 证明 before 的 27 次分配被标量替换，按 0140/0157/0159 先例保留）
- 各基准类 main 等价性自检全部 ALL OK（五种框架场景逐位置坐标矩阵 / 逐位 AABB 矩阵 / 四种监听器场景流程矩阵）
- 复测裁决：ConduitShapeScanBench 初版 Level 复刻 ringIndex 全枚举应答（O(125)/查询）淹没分配差异，初版数据作废；修正为 O(1) 预计算查询后复测

## 兼容性

- API 零变更；0165 快路仅在零监听器时短路，有监听器路径逐字节保留
- 0163 scratch 不入逃逸分支（仅 isWaterAt/getBlockState 坐标读取）；入表实例为坐标拷贝新对象，无双入表分歧（BlockState.is 至多命中一个 VALID_BLOCKS）
- 0164 逐位等价经矩阵自检（边界坐标 ±30000000/i=0/多档世界高度）
- 0165 等价支点：快路检查与事件派发同为 PreCreatureSpawnEvent 静态 HandlerList；零监听器时事件构造为纯分配无副作用（cancelled/shouldAbortSpawn 恒默认），flag 仅在 !callEvent 分支置位
- AttributeMap 缓存评估结案：实例级 dirty/cachedValue 缓存已存在（AttributeInstance），map 级缓存价值不足且 registerAttribute 旁路失效链不可闭合，不做
- 无新增配置项
