# Papo 0.2.0 发布说明

- 基线：Minecraft 1.21.11 / Paper 上游（分支 ver/1.21.11）
- 产物：`paper-server/build/libs/Papo-1.21.11-0.2.0.jar`
- 红线保持：全部优化行为等价或配置门控（默认与现状一致），完整 test 套件 + applyPatches 全绿

## 新增优化（补丁 0071-0077，自 0.1.0 以来含 0069/0070）

### 序列化/网络
- **0074 Identifier.toString() 惰性缓存**：不可变类 + volatile 良性竞态；注册表同步、配方、声音、方块实体 NBT 保存等所有 Identifier 写出路径免去每次字符串拼接（基准 **16.5×**）
- **0075 NBT int/long 数组批量写出**：ByteBuffer 大端一次编码 + 单次 write（0068 读侧的对称面；int **9.3-9.6×**、long **5.4-6.3×**），区块保存路径
- **0069 Raid argmin**（2.6-2.8×）、**0070 SignableCommand 早退**（3.1-3.3×）

### 枚举数组克隆消除（Direction）
- **0071-0073** 红石粉/中继器/红石火把/活塞/游泳·两栖寻路/火蔓延 9 文件 13 处 `Direction.values()` 每类私有静态缓存（基准 **2.6×**）
- **0076/0077** 寻路邻居展开 EnumMap→ordinal 索引数组、`Plane.HORIZONTAL` 迭代器分配消除（流体扩散 6 处 + 红石粉 7 处缓存数组）、`getFloorLevel`/流体查询复用 MutableBlockPos（基准 **1.5×**，另省每调用 2 次分配）

## 基准测试体系

- 新增 `benchmark/`：JMH 1.37 微基准套件（10 个基准类），逐行复刻优化前后实现；`./run.sh` 自动下载依赖
- 对比报告：[note/report/perf/2026-07-30-jmh-microbench.md](../report/perf/2026-07-30-jmh-microbench.md)
- 如实记录：0067 NBT 字符串 ASCII 快速路径在微基准基本持平（收益在分配减少而非解码速度，非 ASCII 回退慢 61%）；Vec3 分配消除被 JIT 逃逸分析掩盖（价值在去 EA 依赖）
