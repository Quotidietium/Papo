- 基线：Minecraft 1.21.11 / Paper 上游（分支 ver/1.21.11）
- 产物：`paper-server/build/libs/Papo-1.21.11-0.18.0.jar`
- 红线保持：行为等价（全部改动经逐分支/逐位/语义等价论证），完整 test 套件 + applyPatches 全绿（1095 patches：sources 918 + features 171 + resources 6）
- **游戏版本红线：始终保持 Minecraft 1.21.11**

## 新增优化（0169–0171，共 3 个补丁，弹射物专题）

- **0169 弹射物候选循环 inflate(0) 跳过两处**：getPickRadius 站点（每候选实体，常规生物半径为 0）**6.47×**；margin 站点（年轻弹射物 margin=0）**8.78×**。inflate(0) 对实体包围盒值等价（min-0.0==min 含 -0.0；makeBoundingBox maxes 不可能 -0.0，max+0.0==max），下游 clip/contains 纯读
- **0170 canHitEntity 谓词实例提升为 Projectile 字段**：8 处每 tick 捕获 lambda 分配消除（**1.20×**；方法引用虚分派语义与每次新建完全一致，Pufferfish 缓存 lambda 同模式）
- **0171 AbstractArrow 命中扫描盒折叠 2→1**：findHitEntity/findHitEntities 两处（**1.25×**；与 0167 同一表达式同一变换）
