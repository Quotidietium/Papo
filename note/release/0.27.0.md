# Papo 0.27.0 发布说明

- 基线：Minecraft 1.21.11 / Paper 上游（分支 ver/1.21.11）
- 产物：`paper-server/build/libs/Papo-1.21.11-0.27.0.jar`
- 红线保持：行为等价（默认全保现状）、API 零变更、游戏版本红线 1.21.11 不变
- **游戏版本红线：始终保持 Minecraft 1.21.11**
- 性质：**安全加固**——针对用户报告的"作弊客户端读取服务端数据推测装了哪些插件"，新增 `fingerprint-hardening` 可控开关（非性能优化）

## 背景

用户报告：作弊客户端可读取服务端数据，推测服务器装了哪些插件。批次 50 三路 survey 之一的"插件指纹泄露"已完整测绘全部向量。本轮落地 paper-global.yml 的 `fingerprint-hardening` 区段，覆盖三个**纯 paper-server、客户端被动接收**的泄露向量（用户"被动读取"痛点的核心）。

## 新增（补丁 0205 + 3 处直接提交）

`paper-global.yml` 新增 `fingerprint-hardening` 区段，**默认全部保持现状（兼容性红线）**，服主可 opt-in：

| 开关 | 默认 | 隐藏什么 | 客户端可达性 |
|---|---|---|---|
| `brand-payload.mode` | `REAL` | `minecraft:brand` 的服务端品牌名 "Papo"（F3 可见） | 配置阶段被动接收 |
| `status.version-string` | `REAL` | ping 版本串 "Papo 1.21.11" | **未登录即可读** |
| `plugin-channels.broadcast-mode` | `ALL` | `minecraft:register` 广播的 incoming channel 名（常可识别插件） | 登录后被动接收 |

每个开关支持 REAL / VANILLA / CUSTOM（brand、status）或 ALL / WHITELIST / NONE（plugin-channels）。`plugin-channels` 另有 `allowed-channels` 白名单。

- **0205（补丁）**：`ServerConfigurationPacketListenerImpl.startConfiguration` 的 brand payload 经 `GlobalConfiguration.fingerprintHardening.brandPayload.resolve(...)` 解析（NMS 读 GlobalConfiguration 是既有模式）。
- **直接提交**：`PaperServerListPingEventImpl` ping 版本串解析；`CraftPlayer.sendSupportedChannels` 逐 channel `shouldBroadcast` 过滤（过滤后空则不发 REGISTER）；`GlobalConfiguration` 新增 `FingerprintHardening` 区段。

详细报告：[note/report/2026-08-02-fingerprint-hardening.md](../report/2026-08-02-fingerprint-hardening.md)。

## 兼容性

- **API 零变更；默认行为与 0.26.0 逐字一致**（REAL/REAL/ALL）；config 未加载时（极早 ping/join）也回退 REAL/ALL。
- brand/status 仅影响客户端显示文字与统计；`Brand-Id` 仍为 `papermc:paper`（`isBrandCompatible` 不变），不影响协议兼容。
- `plugin-channels` NONE/WHITELIST 下，依赖"客户端先得知服务端监听某 channel"的协议类插件（如老式 BungeeCord 联动）可能受影响——opt-in 前建议测试服验证。
