# Papo 0.3.0 发布说明

- 基线：Minecraft 1.21.11 / Paper 上游（分支 ver/1.21.11）
- 产物：`paper-server/build/libs/Papo-1.21.11-0.3.0.jar`
- 红线保持：全部优化行为等价（补丁内注释给出等价性论证），完整 test 套件 + applyPatches 全绿
- **游戏版本红线：始终保持 Minecraft 1.21.11**

## 新增优化（补丁 0078-0091，共 14 个）

### Bukkit 事件无监听器门控（0050 同款模式）
- **0078 GenericGameEvent 门控**：每次游戏事件派发（STEP/SPLASH/放置/破坏等）免去事件对象 + Location + registry 查询构建
- **0079 FluidLevelChangeEvent 门控**：每次流体液位变化（2 处分支）免去事件构建与派发

### 游戏事件/红石/邻居更新分配消除
- **0080 红石线信号计算**：getIncomingWireSignal 复用 MutableBlockPos + above 循环不变量外提，每次调用 12 个 BlockPos 分配归零
- **0081 监听器位置检查**：Optional<Vec3>→@Nullable + distSqr 内联为整数差平方和
- **0082 updateNeighbourForOutputSignal**：Plane.HORIZONTAL 缓存数组 + MutableBlockPos
- **0083 容器开启者查询**：谓词已保证类型，stream 二次装箱改直接强转

### 网络编码
- **0084 Utf8String.write**：utf8Bytes 零分配精确长度 + 直写目标 buffer，免每字符串临时 ByteBuf（基准 **3.8-4.5×**，字节级自检一致）
- **0085 writeFixedSizeLongArray**：internalNioBuffer + LongBuffer 批量编码，区块包位存储每区块约 6-12k 次 writeLong 消除（基准 **11.3-16.8×**，字节级自检一致）

### advancements/背包/杂项
- **0086 击杀/命中/交互/拾取触发器 hasListeners 早退**：无监听器时免每次 LootContext 急切构建
- **0087 Slot.tryRemove @Nullable 内部路径**（safeTake/doClick 免 Optional+lambda）+ carried SlotAccess 每 menu 缓存
- **0088 Ingredient.testOptionalIngredient 三目化**（每配方格匹配）
- **0089 SleepStatus 双 stream 合单遍**（基准 **1.4-3.5×**）+ ServerFunctionManager 空表早退

### 区块加载/NBT
- **0090 区块加载 stream 消除**：实体/方块实体列表、SavedTick 过滤（基准 **1.5-39×**，空表早退 39×）、双重哈希查找提升、区块包预尺寸
- **0091 CompoundTag.accept fastIterator**（0040/0047 同款模式的遗漏点）
