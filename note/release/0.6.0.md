## 新增优化（补丁 0104-0105，共 2 个）

### 实体每 tick 热路径分配消除
- **0104 Entity.updateFluidHeightAndDoFluidPushing 每调用 3 处分配消除**：水/岩浆流体检测每实体每 tick ×2 调用，消除每调用的 `deflate` AABB（边界算术内联，逐运算位级一致）、`MutableBlockPos`（逐实体复用，已实证传入 getHeight/getFlow 的 pos 不逃逸——Paper 运行时 Fluid 实现封闭于 5 个 vanilla 实例）、单 chunk sections 包装数组（常态直引用，索引恒 0 有实证）
- **0105 Entity.computeSpeed 每 tick Vec3 分配消除**：`lastKnownSpeed`/`lastKnownPosition` Vec3 字段 → 分量 double + valid 标志；`getKnownSpeed()` 惰性重建 Vec3（唯一消费方 KineticWeapon 动能武器攻击为低频事件）；`hasMovedHorizontallyRecently` 内联 `Math.sqrt(x*x+z*z)`（与 `Vec3.horizontalDistance()` 逐运算一致）
