- 基线：Minecraft 1.21.11 / Paper 上游
- 产物：`paper-server/build/libs/Papo-1.21.11-0.47.0.jar`
- 红线保持：默认行为等价、线上字节恒等、API 零变更、游戏版本红线 1.21.11 不变
- **游戏版本红线：始终保持 Minecraft 1.21.11**
- 性质：**多玩家网络稳定——编码阶段 memo + SectionBlocksUpdate 广播共享**（批次 73，多观众出站
  冗余全面清算收尾）

## 新增优化（0244）

### 编码阶段 memo（PapoSharedWireMemo 编码字节槽）
首连接 `PacketEncoder` codec 走查的**原样快照**，后续连接 `writeBytes` 直放——与压缩段 memo
（0242）同构；仅对瞬态广播包 arm（随包 GC，无长期内存面）。

### ClientboundSectionBlocksUpdatePacket 双 memo 接入
大红石装置/TNT 大炮场景：`broadcastChanges` 把同一 section 批量更新包发给每 chunk 全部追踪玩家
（每 tick 每 section 数十~数百方块变更）——此前每观众各自 varlong 走查编码 + DEFLATE。

### ClientboundLightUpdatePacket 补 arm 编码 memo
批次 72 的光照广播包在压缩 memo 之上补编码 memo（~16KB codec 走查 → memcpy）。

### 否决留档
`ClientboundExplodePacket` 共享：构造参数含 per-player 击退向量（ServerLevel:1991 逐玩家构造），
不可共享。多观众出站冗余面至此封闭。
