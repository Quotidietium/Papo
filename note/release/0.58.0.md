# Papo 0.58.0 发布说明

- 基线：Minecraft 1.21.11 / Paper 上游
- 产物：`paper-server/build/libs/Papo-1.21.11-0.58.0.jar`
- 红线保持：默认行为等价、API 零变更、游戏版本红线 1.21.11 不变
- 性质：**多核调度⑪——稳态 tick 相位剖析基建**（批次 90，诊断工具轮）

## 新增（批次 90）

### opt-in tick 相位剖析器
`-Dpapo.tickProfile=true`（默认关，关闭时每相位仅一次静态布尔检查）聚合
tickChildren 各段（functions/worlds/connection/players/sendChunks）与每世界
ServerLevel 各段（tickPending/chunkSource/entities）的主线程墙钟，每 400 ticks
打印占比。诊断基建：批次 90 survey 实测稳态主线程利用率仅 3-9%（10 行走 bot），
connection 4-6%、区块发送 ≈1%——网络与区块管线主线程足迹极小；最大单项为空维度
固定成本（上游已有 disable-world-ticking-when-empty 配置旋钮）。
