# Papo 0.59.0 发布说明

- 基线：Minecraft 1.21.11 / Paper 上游
- 产物：`paper-server/build/libs/Papo-1.21.11-0.59.0.jar`
- 红线保持：默认行为等价、API 零变更、游戏版本红线 1.21.11 不变
- 性质：**多核调度⑫——停机窗口稳定性加固**（批次 91，稳定性轮）

## 修复（批次 91）

### 离线程存档管线停机窗口竞态
批次 79/82 的 `PapoOrderedFileWrites`（玩家存档离线程写 + join 读预取）在关服尾部
IO 池排空窗口（`isActive()` 仍为 true 但 `queueTask` 抛 `IllegalStateException`）存在
提交竞态：**写任务会被静默丢弃（丢档）**，读预取的 result future 永不完成（消费方
60s 有界等待，stats/advancements 消费方为无界 join，存在关服竞态下的挂起风险）。
修复：提交 executor 捕获该异常**就地降级同步执行**——与既有"池已停则同步写"的耐久性
契约统一；关服竞态下存档不丢、读必然完成。另修复 `awaitPending` 吞中断不恢复标志。

- 触发条件：登录进行中关服（authenticator 线程读预取与 `haltExecutors` 并发），窗口
  极窄；修复后该类问题整类消除。
- 残余接受面（注释留档）：`halt(false)` 强制停（仅 60s 优雅停机超时后可达）提交侧
  不可检测，该窗口丢写等同 watchdog 强杀，vanilla 同步存档同样无法幸存。
- 正常运行路径零行为变化（不抛异常时与原提交完全同构）。

## 验证

- HaltRaceBench 修复前后对拍 G1-G5 全绿（丢档→执行、悬挂→完成、链健康、中断恢复）；
- 全量 test / 四态冒烟（10/10 join 零异常，稳态 18.4ms 持平批次 88 基线）/ fat-dat
  20-bot burst（p50 3384ms 在历史带宽内）全绿；
- 新增 ShutdownRaceVerify 实弹门（12 bot 登录突发中关服）：exit 0、playerdata 全部
  .dat 合法、同目录重启正常；pre-fix 对照 jar 0.58.1 A/B 复现证明门有效性。
- 该门另捕获一个**上游既有**关服竞态 ERROR（`isStopped()` 后 `server.execute` 内联
  执行于 worker 的 POI 主线程断言，新生成区块无数据影响），A/B 归属上游、非 Papo
  回归，race 门单独披露计数。

## 兼容性

- 默认行为仅在关服竞态窗口内从"静默丢档/悬挂"变为"同步降级"（更接近 vanilla 同步
  语义）；正常运行零变化；API 零变更。
