- 基线：Minecraft 1.21.11 / Paper 上游

- 性质：**多核调度②——玩家存档文件管线下放**（批次 79）

## 新增优化（批次 79）

### 玩家存档写异步化（.dat / stats / advancements）
玩家保存的 GZIP 压缩与三份文件写入此前全部在主线程执行（自动存档突发 =
多 ms tick 尖峰，`/save-all` 与关服全量阻塞）。现主线程只做载荷快照，文件写
下放到 IO 池：

- 同一目标文件严格串行（CompletableFuture 链）——旧快照永不覆盖新快照。
- 三个加载点（重连读档、stats、advancements）读前等待 pending 写——快速重连
  必读最新，与同步语义一致。
- `/save-all`、关服、紧急保存等全量路径等待写完成（vanilla 契约保持）；增量
  自动存档 fire-and-forget。
- 文件字节与同步路径逐字节相同（同一 GSON/NbtIo 调用）。
