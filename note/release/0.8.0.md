# Papo 0.8.0 发布说明

- 基线：Minecraft 1.21.11 / Paper 上游（分支 ver/1.21.11）
- 产物：`paper-server/build/libs/Papo-1.21.11-0.8.0.jar`
- 红线保持：全部优化行为等价（HandlerList 继承关系经 paper-api 源码实证；默认取消规则逐分支比对），完整 test 套件 + applyPatches 全绿
- **游戏版本红线：始终保持 Minecraft 1.21.11**

## 新增优化（0112-0113，共 2 项）

批次 31 暂缓项中两项经实证后回头落地。

- **0112 ItemEntity.playerTouch 双事件门控**（PlayerPickupItemEvent/EntityPickupItemEvent，补丁）：两事件均无监听器时复现默认取消规则（`!getCanPickupItems()` → 恢复 count 返回；否则跳过双事件与 getBukkitEntity），物品成串拾取场景每拾取省 2 事件 + 2 次派发
- **0113 CraftEventFactory.handleBlockFormEvent 零监听器门控**（直接提交的源码，无补丁文件）：结冰/积雪/冰霜行者/雪傀儡每次方块形成跳过 BlockFormEvent 构造直接 place。关键实证：`EntityBlockFormEvent` 不声明自己的 HandlerList（继承 BlockFormEvent 静态列表），单一检查覆盖两种事件形态

## 基准测试

- 两项均为事件门控，与批次 29 EventGateBench（零监听器 16.3×、有监听器无劣化）同型，不重复测量
