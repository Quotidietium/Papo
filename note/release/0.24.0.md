## 新增优化（0193–0195，共 3 个补丁）

批次 46 暂缓清单清算——交互事件门控×2 + goal 目标缓存。JMH 实测 **3 项全部正收益（1.46×–8.58×，CI 均不重叠）**：

- **0193 SWAP_ITEM_WITH_OFFHAND 零监听器门控**（**8.05×**）：每次 F 键交换省 2×asCraftMirror + 2×clone + 事件 + callEvent；等价支点——clone 与 mirror 的 `CraftItemStack.equals` 恒 true，零监听器时必走默认交换分支
- **0194 handleInteract 实体交互双事件零监听器门控**（**8.58×**）：每次实体右击/精准右击省事件构造 + getBukkitEntity + callEvent + resendData 判定链；两事件各自独立 HandlerList（逐文件实证）按调用点分别门控，null-event 重结构避免改动匿名 Handler
- **0195 MoveToBlockGoal.getMoveToTarget above() identity 缓存**（**1.46×**）：每活跃 goal（猫/兔/海龟/僵尸拆门等）每 tick 省 1 BlockPos；blockPos 只重赋值从不原地 mutate（11 子类全库审计），identity 失效信号完备
