# 0.117.0（批次 209，2026-10-27）

Java 25 全面迁移（用户决断）：编译工具链、类文件版本与运行时全面升到 Java 25。**插件兼容不受影响**——插件仍按上游 Paper 1.21.11 编译（v65 类在 25 上正常加载，真机实证）。

## 变更

- 根 `build.gradle.kts`：工具链与 `options.release` 21 → 25（类文件 v65 → v69，包内 javap 实证）
- run 任务：去掉 JETBRAINS JDK 21 vendor 钉（标准工具链解析），移除 JBR 专属 `-XX:+AllowEnhancedClassRedefinition`
- 测试栈：mockito 5.14.1 → 5.20.0（旧 ByteBuddy 不识 v69——迁移前 142/297 测试挂的唯一根因）
- SmokeJoinVerify：起服 JVM 用 `File(java.home, "bin/java.exe")` 绝对路径（含空格路径 + 无 .exe 时 CreateProcess error=2）

## 验证

- `compileJava --rerun-tasks --no-configuration-cache`（工具链 25）一次通过：paperweight 2.0.0-beta.19 与反编译源码在 javac 25 下零错误
- 全量测试套件全绿（mockito 升级后）
- **JDK 25 真机冒烟**：10/10 join、exit=0、logErrors=0、dat/stats/advancements 全 OK、稳态 join p50=22ms

## 性能与运维注记

Java 25 运行时收益入口：`-XX:+UseCompactObjectHeaders`（JEP 519，对本内存优化型服务端收益最大）、分代 ZGC、JIT 改进——建议以 COH 开旗做一轮配对浸泡量化。mcVersion=1.21.11 与 paperweight beta.19 红线不变。
