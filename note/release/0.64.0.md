## 新增（批次 102）

### 实体追踪扇出分解探针（诊断，默认关）
`-Dpapo.tickProfile=1` 时新增 `chunkMap.tracker.fanout` 相位（逐 viewer 投递环计时），
与既有 sendChanges 总量做差即包构建成本。用于聚堆规模下的广播面归因：
实测扇出占面 >92-99%，包构建 <8%，每对投递 ~90ns 为上游快路径——该面为追踪语义
本体，无默认行为等价前提下的削减空间。默认关闭，生产零开销。
