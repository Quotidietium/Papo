# Papo 0.39.0 发布说明

- 基线：Minecraft 1.21.11 / Paper 上游
- 产物：`paper-server/build/libs/Papo-1.21.11-0.39.0.jar`
- 红线保持：默认行为等价、API 零变更、游戏版本红线 1.21.11 不变
- **游戏版本红线：始终保持 Minecraft 1.21.11**
- 性质：**容器/菜单域零监听器事件门控**（批次 65，批次 49 暂缓清单回头攻克：三落地两否决）

## 新增优化（0228/0229 + 直提交）

### 直提交 — PrepareResult 全族零监听器快路
- 一张 HandlerList（PrepareInventoryResultEvent）覆盖 anvil/grindstone/smithing/loom/stonecutter/cartography/combiner 七个调用点；零监听器时仅保留 broadcastChanges，省事件构造+instanceof 链+值恒等回写。
- **铁砧改名每击键**、各结果菜单每次输入变化省 ~3 分配。

### 0228 — InventoryCreativeEvent 零监听器快路
- InventoryClickEvent 父表共享（与既有 InventoryClickEvent 快路同键）；快路一句 `packet.itemStack().copy()`（拷贝链逐例恒等）。创造模式每次背包点击/放置/丢弃省 view+bukkit 拷贝+事件+派发+switch。模型 2.41×。

### 0229 — InventoryDragEvent 零监听器快路
- doClick QUICK_CRAFT 多槽分支；逐句保留两段 setCarried（防复制预写 + 原路径末写）与 view.setItem 循环，仅省事件侧机制。9 槽模型 1.88×（CI 极窄）。

## 两项否决（证据留档）

1. **RecipeManager nullable 内部核**：gc 探针实证 before/after 同为 16 B/op——中间 Optional 跨方法但被内联，EA 直接消除，手工拆包零收益（判例：内联的 Optional 包装链不值得手工拆）。已实现后撤回。
2. **CraftingInput 缓存**：失效信号不可闭合——vanilla `ServerPlaceRecipe` 的 `grow()` 原位变异网格活栈 + 插件镜像/活 list 通道 + 别名栈使 equals 校验恒真；收益上限仅每 craft 1/10 次构造。不做。
