# Papo 0.13.0 发布说明

- 基线：Minecraft 1.21.11 / Paper 上游（分支 ver/1.21.11）
- 产物：`paper-server/build/libs/Papo-1.21.11-0.13.0.jar`
- 红线保持：行为等价（全部改动经逐分支/逐位/语义等价论证），完整 test 套件 + applyPatches 全绿（1078 patches：sources 918 + features 154 + resources 6）
- **游戏版本红线：始终保持 Minecraft 1.21.11**

## 新增优化（0150–0154，共 5 个补丁 + 1 项直接提交）

AI 框架层开销（村民等生物每 tick 高频路径）：

- **0150 ValidateNearbyPoi 手写 OneShot + Brain 原生读**：声明式 BehaviorBuilder 链（每次 tryStart 分配 MemoryAccessor + Optional.map + 应用闭包层）改写为类级语义相同的手写 OneShot；新增 `Brain.papoGetMemoryInternalRaw` 直出可空引用，免 Optional 包装（1.25×）
- **0151 Behavior.tryStart tickRate 缓存**：每停止行为每实体每 tick 的 `tickRates.behavior` Table.get 双哈希+拆箱，按（配置纪元， 世界配置引用）双键缓存为 volatile 长读+引用比较（6.40×）
- **0152 Sensor.tick tickRate 缓存**：同构缓存，默认 scanRate 语义不变（与 0151 同基准 6.40×）
- **直接提交（0155）PAPO_CONFIG_EPOCH 配置纪元**：`PaperConfigurations.reloadConfigs` 开头递增 volatile 纪元，为 0151/0152 提供 `/paper reload` 失效钩子；放在开头保证部分失败也保守失效

网络与物品路径：

- **0153 ItemStack 解码 CountingOps RegistryOps 缓存**：每个非空入站物品栈解码省 RegistryOps+HolderLookupAdapter+ConcurrentHashMap 三连分配（10.60×；0133 NBT 同构机制，接入 ImmutableRegistryAccess volatile 缓存）
- **0154 handleContainerClick InventoryClickEvent 零监听器快路**：监听器为空时跳过整个点击/动作映射 switch（约 200 行）、Bukkit 视图包装与事件派发，直接 clicked + 合成/锻造条件重同步（3.85×；QUICK_CRAFT 分支逐字保留，有监听器路径逐字节保留）
