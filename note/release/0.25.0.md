- **游戏版本红线：始终保持 Minecraft 1.21.11**

## 新增优化（0196–0202，共 7 个补丁）

批次 49 三路 survey（容器/菜单、区块IO/保存、AI/Brain）28 候选中**已验证低风险子集**：4 个零监听器事件门控 + 3 个实体扫描 scratch-list（复用 0190 模式）。JMH 实测 **5 项正收益（1.10×–6.68×，CI 不重叠）、2 项机制保留（gc 探针证分配消除、复刻浅栈 JIT 伪影）**：

- **0196 TradeSelectEvent 门控**（**6.06×**）：村民交易选项点击省 getBukkitView+事件+callEvent
- **0197 BlockBurnEvent 门控**（**6.68×**）：火烧毁判定省 CraftBlock×2+事件（森林火灾/岩浆引燃高发期显著）
- **0198 CauldronLevelChangeEvent 门控**（**5.85×**）：炼药锅水位变化省 CraftBlockState+CraftBlock+事件（炼药锅无方块实体，零监听器时 setBlock == newState.place）
- **0199 岩浆引火 BlockIgniteEvent 门控**：补齐 FireBlock:231 已有模式（火蔓延已门控、岩浆两处漏网）；复刻浅栈内中性、真实深栈 EA 无法消除，机制保留
- **0200 AvoidEntityGoal scratch list**：苦力怕/骷髅/兔/海龟避敌扫描复用 per-goal scratch；gc 探针证分配消除（416→0 B/op），机制保留
- **0201 FollowParentGoal scratch list**（**1.10×**）：繁殖场幼体扫描
- **0202 NearestItemSensor scratch list**（**1.12×**）：猪灵/悦灵/狐狸拾取扫描（sensor per-entity，sort+迭代后丢弃）
