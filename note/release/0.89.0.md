# 0.89.0（批次 156 / R16：shape 族规范共享）

内存占用继续下降：多玩家多区块加载驻留场景（12 玩家、视距 10）配对浸泡
**−40.1MB（−6.52%，保守口径：优化侧多载 3.15% 区块仍胜）**，每区块全量
143.8→130.3KB。

## 变更

- 新增 `PapoShapeCache`：状态缓存形状（碰撞/遮挡）规范共享表——结构相等的
  bitset 背书 ArrayVoxelShape 坍缩为每几何一个实例；惰性子结构（面向形状、
  AABB 列表、Moonrise 碰撞缓存）随规范根每几何一份。
- 挂点仅两处长寿命缓存写入（`BlockBehaviour.BlockStateBase$Cache` 构造器与
  `initCache()`）；瞬态形状不入表（表大小被注册表不同几何数严格上界）。

## 依据

转储普查：全堆 345,808 个 AABB 仅 3,256 个不同几何（99.1% 结构重复）；本批后
AABB −79.3%、ArrayVoxelShape −72.6%、BitSetDiscreteVoxelShape −73.3%、
DoubleArrayList −70.4%（逐位确定性归因，机器无关）。

## 兼容性

- 几何逐位不变；`Shapes.empty()/block()` 单例永不被替换，`==` 单例比较语义不变；
  Bukkit `getCollisionShape` 包装逐调用新建，API 语义不变。
- 验证：`:paper-server:test` 8,960 全绿（新增 PapoShapeInternTest 7 项）；
  applyPatches 全量重放 EXIT=0；check_patch_counts ALL OK；compileJava
  --rerun-tasks BUILD SUCCESSFUL。

## 升级

替换 `Papo-1.21.11-0.89.0.jar` 即可，无配置与盘格式变化。
