# Papo 0.14.0 发布说明

- 基线：Minecraft 1.21.11 / Paper 上游（分支 ver/1.21.11）
- 产物：`paper-server/build/libs/Papo-1.21.11-0.14.0.jar`
- 红线保持：行为等价（全部改动经逐分支/逐位/语义等价论证），完整 test 套件 + applyPatches 全绿（1082 patches：sources 918 + features 158 + resources 6）
- **游戏版本红线：始终保持 Minecraft 1.21.11**

## 新增优化（0155–0158，共 4 个补丁）

- **0155 Varint21FrameDecoder 内联 varint 解析**：每个入站帧消除 helperBuf（direct 缓冲）逐字节抄写、clear() 与 VarInt.read 二次解析；读取同时内联累积长度前缀（JMH 1.04-1.05× 小幅正向，survey 定级"低价值"实测相符；读者索引与异常行为逐路径保持）
- **0156 EntitySelector.getPredicate 上下文无关路径组合谓词缓存**：`@e[type=...]` 类选择器（无 features/box/range）每次执行省 `Util.allOf` 捕获 lambda 分配（1.15×；contextFreePredicates 为 List.copyOf 不可变快照，allOf 纯函数惰性缓存）
- **0157 MapItemSavedData.addDecoration 稳态比较优先**：携带地图的玩家静止（装饰未变）时每 tick 每携带者省 Pair+位置记录+MapDecoration 三处分配，仅变化时分配并标脏（JMH 复刻内持平——EA 抹除复刻分配差，机制性收益按 0140 先例保留；put 语义、迭代序、计数/标脏条件逐分支保持）
- **0158 tickCarriedBy 地图匹配谓词内联**：每张携带地图每 tick 省捕获 lambda 分配与 Predicate 间接分派（1.69×；逐项测试与背包迭代序逐字保持）

## 基准测试

- JMH 对比报告：[note/report/perf/2026-08-01-jmh-microbench-batch38.md](../report/perf/2026-08-01-jmh-microbench-batch38.md)

## 兼容性

- API 零变更
- 0155 读者索引结局逐路径相同（前缀不全/负载不足 → reset；超宽/零长 → 消耗前缀后抛异常不 reset）；带宽监控计数 `monitor.onReceive` 逐字保留
- 0156 缓存仅影响 i==0 分支；谓词无状态可重入，跨调用判定一致
- 0157 相等时跳过 put：LinkedHashMap 已存在键 re-put 不改变迭代序，全部消费方按值读取（CraftMapRenderer/PaperMapDecorations/地图更新包），实例身份无 API 可观察路径
- 编号说明：0155 被两批使用——批次 37 的 0155 是直接提交（PAPO_CONFIG_EPOCH，无补丁文件），批次 38 的 0155 起为补丁文件编号（同 0114/0150 先例，以补丁文件序列为准）
