# Papo 0.5.0 发布说明

- 基线：Minecraft 1.21.11 / Paper 上游（分支 ver/1.21.11）
- 产物：`paper-server/build/libs/Papo-1.21.11-0.5.0.jar`
- 红线保持：全部优化行为等价（补丁内注释给出等价性论证；0096/0097/0103 附字节级或行为级自检实证），完整 test 套件 + applyPatches 全绿
- **游戏版本红线：始终保持 Minecraft 1.21.11**

## 新增优化（补丁 0096-0103，共 8 个）

### 网络解码
- **0096 FriendlyByteBuf.readNbt ThreadLocal 轻量 DataInput 适配器**（0095 读侧镜像）：入站 NBT 解码每次分配 `ByteBufInputStream` 改为 ThreadLocal 复用；javap 实证 Netty 4.2.7 逐方法语义（EOF 返回 -1 与 EOFException 的分工、skipBytes 静默截断、readLine 本地计数不抛异常、异常消息逐字符相同）后 1:1 复刻，基准 main 对真实 Netty jar 逐方法行为比对全等
- **0097 VarInt.read 单字节快速路径**：包 id/集合长度/枚举序数（全部 < 128）免去循环；多字节路径保持逐字节语义含第 6 字节异常时机（基准 1 字节 **1.16×**）
- **0098 readEnum/writeEnumSet/readEnumSet 枚举常量数组缓存**：ClassValue 缓存，免 `getEnumConstants()` 每次克隆整个常量数组（基准 readEnum **4.30×**、writeEnumSet **1.96×**）
- **0099 ByteBufCodecs.registry 无状态 codec 静态单例**（AddEntity/BlockEvent/区块包方块实体 3 个包类）：免每次 encode/decode 新建匿名 StreamCodec；注册表仍每次从 buffer 解析，运行时变化照常生效

### 事件门控与分配消除
- **0100 EntityJumpEvent(3 处)/PlayerVelocityEvent 无插件监听器门控**：跳跃（寻路翻越/史莱姆）与击退路径常态零分配（基准零监听器 **16.3×**，有监听器无劣化）
- **0101 GameEventDispatcher.post BY_DISTANCE 队列 + Player.aiStep 经验球列表惰性分配**：每次游戏事件 post 与每玩家每 tick 的空 ArrayList 消除
- **0102 TrackedEntity 清理循环防御性 seenBy 拷贝 → 惰性移除列表**（2 处）：玩家进出追踪范围时每个被追踪实体每 tick 的全量拷贝消除（基准 **42.7×**）

### 区块 IO
- **0103 RegionFileVersion DEFLATE 读侧 Inflater ThreadLocal 池化 + fill 缓冲 512→8192**（0066 写侧镜像）：每次区块/实体/POI 读盘省一次 native inflateInit/end + Cleaner 注册（基准 **1.09-1.15×**；javap 实证 JDK 21 外部 Inflater close 不 end，真实 zlib 三尺寸×复用 3 轮+双流并发逐字节自检全等）

## 数据驱动撤销（1 个）

- **ByteBufCodecs.map / FriendlyByteBuf.writeMap 的 forEach→entrySet**：JMH 实测 7 条目（区块包高度图规模）回退 **0.77×**（HashMap.forEach 直接扫内部表、捕获 lambda 被 JIT 逃逸分析消除），已从内部历史摘除该提交。教训与数据保留在 [optimizations.md](../optimizations.md) 批次 29 撤销条与基准类 MapEncodeLoopBench。

## 基准测试

- benchmark/ 新增 8 个基准类（NbtReadAdapterBench 含对真实 Netty jar 的逐方法行为自检 main；InflaterPoolBench 含真实 zlib 逐字节自检 main；其余含行为等价自检）
- 对比报告：[note/report/perf/2026-07-31-jmh-microbench-batch29.md](../report/perf/2026-07-31-jmh-microbench-batch29.md)
