# Papo 0.57.0 发布说明

- 基线：Minecraft 1.21.11 / Paper 上游
- 产物：`paper-server/build/libs/Papo-1.21.11-0.57.0.jar`
- 红线保持：默认行为等价、API 零变更、游戏版本红线 1.21.11 不变
- 性质：**多核调度⑩——登录相位事件驱动**（批次 88）

## 新增优化（批次 88）

### 登录完成事件驱动
认证线程完成（含 AsyncPlayerPreLoginEvent）后，LoginSuccess 原本要等下一个服务器
tick 才发送（0-50ms 量化等待）。现在立即经主线程任务队列推进（守卫与常规 tick 路径
逐字相同），单次执行由主线程串行化与状态转移共同保证。

## 基准

- 登录相位：21ms → **4ms**；稳态重连 join：**80ms → 14-15ms（−82%）**（与批次 87

  fat-dat 突发均改善且零异常。
