## 常量区块节规范化共享（节/容器实例层坍缩）

- 一个"整个内容 = 单一方块状态 + uniform biome"的节（天空节、均匀石节：
  实测占节总数 19.2%）不持有任何逐 chunk 状态，但各占节壳 40B + 双容器壳
  48B + 双 Data/palette 壳 ~80B + tick 列表壳 24B ≈ 224B。现坍缩为每
  (方块, biome) 每世界注册表一个规范共享实例——被坍缩节的六件套全部归零，
  容器并与全服常量容器共享单值 Data（批147）。
- 安全契约：均匀性按**格子内容**判定（零位存储快路径 → raw long 全等 → 逐格
  核对），与 palette 表示型无关——世界生成经写路径构造的均匀节（单条目
  LinearPalette）同样命中；随机刻/流体刻/特殊碰撞/混合/未注册 biome/客户端
  节保持私有。写者面枚举后收口六门（setBlockState×2/setBiome/
  fillBiomes/doFill/OreFeature），air-into-air 快路径使最常见写永不物化；
  每个节变更器内置响亮金丝雀——漏门写者立即崩溃而非静默腐蚀共享者。规范节
  以 vanilla 单值 palette 编码落盘（内容逐格恒等、更小、全版本可解码）。
- 浸泡两腿实测（12 bot、6,080 vs 6,098 区块配对，门全绿）：堆 797.1 →
  780.0MB（**−2.14%**）；归因闭合：节 −76,126（−19.2%）× 224B = 17.0MB，
  内容面（光照 nibble/palette 载荷）每区块率持平。
