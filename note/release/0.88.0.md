## 结构模板驻留解耦（piece 惰性取 + 有界管理器缓存）

- vanilla 把每个载入过的结构模板（村庄/掠夺站/沉船/化石等的全部方块信息
  表：0.87.0 普查 412 模板 = 495,771 StructureBlockInfo + ~495k BlockPos ≈
  26-28MB）**永久缓存**在全服单例 StructureTemplateManager 的无界映射里，随
  探索面积单调增长、直到重启。本轮双重解耦：
- **piece 惰性取**：TemplateStructurePiece 不再强持模板实例（旧字段会被常驻
  区块的 StructureStart 钉住、令任何缓存上界失效），改持 manager + 标识符用
  时现取；模板名本来就是唯一的序列化内容，盘格式零变化；放置期间模板不可
  变，miss 重载恒等重现。六处子类直接字段访问（Shipwreck×3/OceanRuin/
  NetherFossil/RuinedPortal）改走访问器。
- **PapoStructureCache**（运行时替换，声明类型保持 `Map` 保插件二进制兼容）：
  120s idle-TTL 驱逐 + 服务端 tick 每 ~25.6s 清扫；**put 即保护**——保护域恰
  为全部不可重载来源（getOrCreate 对无源可载 id 的新建 + Bukkit
  register/load-with-register），世界生成热路径（tryLoad 可重载）永远可驱逐；
  **全读路径打访问戳**（get/containsKey/computeIfAbsent/entrySet/values），
  插件轮询原始映射（Bukkit getStructure/getStructures）语义逐字节不变；256
  条可驱逐上限防病态世界。
- 浸泡实测（12 bot 配对门绿，区块 −0.82%）：堆 782,611 → 757,348 KB（门对
  −3.23%）；同会话转储对（6,048 vs 6,046 块近完美配对）**−18.1MB
  （−2.33%，保守取值）**；归因：StructureBlockInfo −227,169 / BlockPos
  −222,500 / 模板 412 → 155（驻留测量点恰逢 TTL 热窗，残留=窗口内条目）；
  **无玩家稳态（240s 补充腿）：B-088 缓存清扫至空（模板簇直方图全零行，
  连保护域都空 = 412 全 tryLoad 背书自证），0.87.0 对照仍持全部 412 模板/
  495,771 infos，差 −28.4MB = 全簇释放**——长跑服务器无界增长闭环。单测
  PapoStructureTemplateCacheTest 10 项（注入时钟：TTL/保护/打戳/上限/重载
  透明性/Map 契约）。
