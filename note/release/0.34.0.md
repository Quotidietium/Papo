## 新增优化（0217）

### 0217 — 零拷贝出站帧化（headroom 前缀 + 身份标记直通）

出站三阶段（编码 → 压缩 → 帧化）原版每包全量拷贝。0217 让 PacketEncoder 预留 6 字节 headroom 前缀并发布 buffer 身份，压缩与帧化阶段原地写各自长度 varint 后直通：

| 路径 | 原版 | 0217 后 |
|---|---|---|
| 低于阈值（默认 256B，**绝大多数游戏包**：移动/音效/心跳/交互） | 2 次全量拷贝 + 3 次池化分配 | **0 拷贝 + 1 次分配** |
| 高于阈值（区块/大包） | 1 次帧拷贝 + 1 次分配 | 0 拷贝（压缩输出写为语义必需） |

- **JMH**（EmbeddedChannel 真实 netty 管线）：belowThreshold 469.7 → 285.7 ns/op（**1.64×**，CI 不重叠）；aboveThreshold 均值正向 7%（压缩主导、CI 重叠，如实记录）。
- **等价性**：线上字节逐字节一致（9 尺寸 × 2 可压性矩阵 + 阈值边界自检 ALL OK）；三阶段均在 channel 单 event loop 的同一次 write 遍历内（无跨线程——与已回退的 0209 不同）；native cipher 以 readerIndex 起算原地加密（javap 实证 headroom 兼容）；身份不匹配全量回退原版拷贝路径。
- **引用计数**：万次写-读-释放压力自检无泄漏；异常路径恰好一次 release（初版双重释放缺陷经审计重写为所有权内聚结构）。
