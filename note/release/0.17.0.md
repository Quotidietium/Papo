# Papo 0.17.0 发布说明

- 基线：Minecraft 1.21.11 / Paper 上游（分支 ver/1.21.11）
- 产物：`paper-server/build/libs/Papo-1.21.11-0.17.0.jar`
- 红线保持：行为等价（全部改动经逐分支/逐位/语义等价论证），完整 test 套件 + applyPatches 全绿（1092 patches：sources 918 + features 168 + resources 6）
- **游戏版本红线：始终保持 Minecraft 1.21.11**

## 新增优化（0166–0168，共 3 个补丁，每 tick 分配链折叠）

- **0166 漏斗吸取路径缓存**：方块漏斗 suck BlockPos 每 BE 一次缓存（containing(x+0.5,y+1.5,z+0.5)==worldPosition.above() 逐位等价）；矿车漏斗 suck pos / suck AABB 位置键控缓存 + 后备拾取 AABB bb 引用键控缓存（纯函数同键同值，NaN 键与 bb 替换自然失效；第三方 Hopper 实现保持原路径）。静止农场收集车每 tick 省 3 次分配（**3.79×**）
- **0167 弹射物命中扫描 AABB 折叠 2→1**：`expandTowards(deltaMovement).inflate(1.0)` 单构造直给（**1.25×**；三元式与原版分支对 NaN 同构，-0.0 边缘被 ±1.0 抹除，左结合 FP 序保持）
- **0168 活塞碰撞实体扫描盒折叠 3→1**：moveByPositionAndProgress→getMovementArea→minmax 链单构造（**1.46×**；六向分支逐字展开，Math.min/max 操作数序对齐，并集恒已归一化）

## 兼容性

- API 零变更；0166 第三方 Hopper 接口实现（非方块漏斗非矿车）全部保持原 per-call 路径
- 0166 缓存失效均为自然失效：worldPosition final（setBlock 重建 BE）、坐标变化键不匹配、bb 引用替换；无钩子依赖
- 0167/0168 逐位等价经矩阵自检（NaN deltaMovement、-0.0 边界、6 方向 × delta 符号 × 细盒/跨零/极薄 bounds）
- 0168 仅改扫描盒构造，活塞对实体的推动逻辑（内层循环）逐字未动
- 无新增配置项
