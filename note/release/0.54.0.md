# Papo 0.54.0 发布说明

- 基线：Minecraft 1.21.11 / Paper 上游
- 产物：`paper-server/build/libs/Papo-1.21.11-0.54.0.jar`
- 红线保持：默认行为等价、API 零变更、游戏版本红线 1.21.11 不变
- 性质：**多核调度③——worker 池默认曲线提升 + level.dat 写下放**（批次 80）

## 新增优化（批次 80）

### chunk 系统 worker 池默认曲线
并行区块生成/加载/光照/压缩/存档的 worker 池 auto 默认从 cores/4 提升为
cores/2 clamp [2,12]（8核 2→4、16核 4→8、24核+ → 12）。探索突发期 worker 池是
吞吐瓶颈而核闲置，主线程等待区块直接造成 tick 卡顿。显式配置与 -D 覆盖优先保留；
worker 线程优先级位于主 tick 线程之下，扩容不偷 tick 时间（基准探针实证偏差 0ms）。

### level.dat 写下放
每世界每自动存档周期的 level.dat gzip+写盘从主线程移至 IO 池（per-文件有序链，
批次 79 机制复用）；启动期路径保持同步；备份前等待 pending 写；`/save-all` 与
关服的 flush 语义保持。
