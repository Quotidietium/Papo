# Papo 0.11.0 发布说明

- 基线：Minecraft 1.21.11 / Paper 上游（分支 ver/1.21.11）
- 产物：`paper-server/build/libs/Papo-1.21.11-0.11.0.jar`
- 红线保持：行为等价（全部改动经逐分支/逐位/字节级等价论证，线程安全性源码实证），完整 test 套件 + applyPatches 全绿（924 patches）
- **游戏版本红线：始终保持 Minecraft 1.21.11**

## 新增优化（0125–0133，共 9 个补丁 + 1 项直接提交）

- **0125 BlockRedstoneEvent 11 调用点迁移零监听器快路**：比较器/中继器/侦测器/阳光探测器/讲台/红石灯/动力轨每次信号变化省 CraftBlock+事件+派发；ContainerOpenersCounter 3 处 fire-and-forget 门控
- **0126 PlayerNaturallySpawnCreaturesEvent 门控+实例复用**：每玩家每 tick 刷怪检查省事件构造；取消/半径变更检出即重建，监听器注册/注销切换全覆盖
- **0127 SerializableChunkData sections Optional 消除**：区块反序列化每区块省约 216 个 Optional（1.17×）
- **0128 addVanillaDecorations rangeClosed 双循环**：每区块省 1 Stream+9 ChunkPos+闭包（1.54×；同文件 holderSet 项实测 0.82× 按延迟否决规则未应用）
- **0129 DEFLATE 写侧 Deflater ThreadLocal 池化**：每次区块保存消除本地 zlib 状态分配+Cleaner 注册（reset 字节级等价自检；池按压缩级别键控）+ deflate 内部缓冲 512→8192 + 外层缓冲 8K→32K
- **0130 TemptingSensor TargetingConditions 字段复用**：每动物每 20 tick 省一次 copy 分配（1.17×；属性运行时变更即时生效）
- **0131 PlayerSensor.getFollowDistance 外提**：逐玩家属性取值降为单次（3.39×）
- **0132 PlayerMoveEvent from/to Location 阈值后延迟构造**：handleMovePlayer/handleMoveVehicle 两处；被 1/256 阈值过滤的移动包（占绝大多数）省 3 个 Location（5.51×），归一化边界矩阵逐位自检
- **0133 ImmutableRegistryAccess 缓存 NBT RegistryOps**：聊天组件/实体元数据/HoverEvent 等一切 Component 包编解码省 RegistryOps+HolderLookupAdapter+CHM 分配（10.97×；ConcurrentHashMap 线程安全实证）
- **直接提交（0134）handleBlockGrowEvent 门控 + handleRedstoneChange 快路**：作物生长/树苗/蘑菇等 21 个调用点零监听器省事件构造；红石快路配合 0125
