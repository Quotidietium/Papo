## 新增优化（0232-0234，编号以补丁文件为准）

### 0232 — 红石粉事件双站点零监听器快路 + HashSet 桶序复刻（同补丁，本批主项）
- 0125/0134 迁移了 11 个红石事件站点，**漏了默认 VANILLA 评估器下频率最高的两个**（DefaultRedstoneWireEvaluator + RedStoneWireBlock.calculateCurrentChanges——每次粉功率变化）。补齐走已有 handleRedstoneChange 快路；红石机器零监听器服粉功率变化不再白建 CraftBlock+事件+空派发。

### 0232（续）— 粉评估器去 HashSet（与事件门控同一补丁）
- 每次粉功率变化的 7 位置 HashSet（恒不去重、恒不扩容，~9 分配）→ 桶序直复刻（邻更新顺序逐字节不变）。**1M 随机位置穷尽对拍真实 HashSet 迭代序 ALL OK**；JMH 1.68×。
- 附判例补正：LinkedHashSet 形态一票否决的正确理由是**插入序≠HashMap 桶序**（会改邻更新顺序→红石可观察），桶序复刻可行。

### 0233 — 红石火把 tick 事件惰性化 + 门控
- 火把时钟 holding-state tick 原本无条件构造 CraftBlock+事件却从不派发——现只在真转换时构造+派发（且带零监听器门控）。等待期分配归零。

### 0234 — 比较器 getItemFrame facing 谓词静态缓存
- 实心导体输入路径的捕获 lambda → 按 Direction 静态缓存（0170 模式）。
