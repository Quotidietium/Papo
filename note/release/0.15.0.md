# Papo 0.15.0 发布说明

- 基线：Minecraft 1.21.11 / Paper 上游（分支 ver/1.21.11）
- 产物：`paper-server/build/libs/Papo-1.21.11-0.15.0.jar`
- 红线保持：行为等价（全部改动经逐分支/逐位/语义等价论证），完整 test 套件 + applyPatches 全绿（1086 patches：sources 918 + features 162 + resources 6）
- **游戏版本红线：始终保持 Minecraft 1.21.11**

## 新增优化（0159–0162，共 4 个补丁，信标专题）

- **0159 updateBase 基座扫描 scratch pos**：每 80 tick 每信标省至多 164 次 BlockPos 分配（纯坐标读取无逃逸；JMH 复刻内 EA 抹平 before 分配，机制性收益经 gc 剖析实证保留）
- **0160 光柱扫描 pos 字段化**：每信标每 tick 省 1 次 MutableBlockPos 分配（实体字段跨 tick 复用，主线程无重入；JMH 复刻数值为 EA 假象已载明，与 0135 字段 scratch 同模式）
- **0161 信标范围 AABB 三次分配折叠为一次**：效果范围查询（每 80 tick 每激活信标）省 2 个中间 AABB（1.57×；浮点结合序与构造归一化逐位保持）
- **0162 BeaconEffectEvent 零监听器快路**：每 80 tick 每激活信标省共享 toBukkit+CraftBlock 与每玩家事件+fromBukkit 往返分配（1.42×；每玩家改发字段相等 copy 副本，duration 就地可变故共享实例不外发）

## 基准测试

- JMH 对比报告：[note/report/perf/2026-08-01-jmh-microbench-batch39.md](../report/perf/2026-08-01-jmh-microbench-batch39.md)
