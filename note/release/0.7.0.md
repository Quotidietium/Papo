# Papo 0.7.0 发布说明

- 基线：Minecraft 1.21.11 / Paper 上游（分支 ver/1.21.11）
- 产物：`paper-server/build/libs/Papo-1.21.11-0.7.0.jar`
- 红线保持：全部优化行为等价（门控类事件经 paper-api 全库 grep 确认无子类、构造无副作用；缓存两段式附不重入/非 null 论证），完整 test 套件 + applyPatches 全绿
- **游戏版本红线：始终保持 Minecraft 1.21.11**

## 新增优化（补丁 0106-0111，共 6 个）

### 事件门控扩展（沿用 0050/0078/0079/0100 已验证模式）
- **0106 FlowingFluid**：BlockFromToEvent 无监听器门控（spread/spreadToSides 2 处——水/岩浆扩散是服务器最热计划刻之一）+ tick 复用传入 state 消除冗余 `getBlockState`（两个调用点均在读取后无插入世界修改，补丁注释固定契约）
- **0107 物品拾取/合并**：PlayerAttemptPickupItemEvent 门控（玩家站掉落物上每 tick 每物品）+ ItemMergeEvent 零监听器早退（省事件 + 2×getBukkitEntity）
- **0108 经验球×4**：PlayerPickupExperience / ExperienceOrbMerge / ExpCooldown / ItemMend 事件门控（XP 农场挂机场景持续高频）
- **0109 移动包处理**：PlayerJumpEvent 门控（每次起跳省 2×Location + 事件）+ `preventMovingIntoUnloadedChunks` 检查 Vec3 差值折叠为单分配（位级一致）

### 容器/寻路/行为 tick 分配消除
- **0110 InventoryMenu.broadcastSlotChange**：memoize supplier 变更门控（逐字照抄本仓库 broadcastChanges 已合入门控；开 GUI 玩家每 containerUpdate tick ×6 槽位）
- **0111 寻路缓存 computeIfAbsent → get+put 两段式**（NodeEvaluator.getNode、WalkNodeEvaluator.hasCollisions/getCachedPathType 3 处——一次 findPath 数千次调用，fastutil computeIfAbsent 不内联导致捕获 lambda 命中也真实分配）+ GateBehavior.tickOrStop 遗留 stream 消除（村民 core activity 长期 RUNNING 每 tick）
