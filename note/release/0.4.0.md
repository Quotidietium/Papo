## 新增优化（补丁 0092-0095，共 4 个）

### NBT 写侧零分配化
- **0092 papoWriteUtf ASCII 快速路径**（0067 读侧的写侧镜像）：NBT 序列化每个键名与字符串值免去 JDK `writeUTF` 的 `byte[utflen+2]` 分配——ASCII 单遍扫描 + `writeShort` + ThreadLocal scratch 分块直写；NUL/非 ASCII 回退 writeUTF，超长委托抛出同一 `UTFDataFormatException`。文件 NBT 与网络 NBT 共用 `Tag.write` 路径，两侧同时受益。字节级自检：空/短/10KB 分块/utf8/NUL/65535 边界全等
- **0095 FriendlyByteBuf.writeNbt ThreadLocal 轻量 DataOutput 适配器**：区块包方块实体与带 NBT 组件物品的编码入口，免去每次 `new ByteBufOutputStream`（0092 落地后该路径最后的 per-call 分配）。javap 实证 Netty `writeUTF` 内部实现（惰性 utf8out 字段）后同构复刻；buffer 字段 save/restore 保证重入正确。字节级自检：对真实 Netty 4.2.7 逐方法 + 树形写出全等

### 事件/同步
- **0093 InventoryChangeTrigger hasListeners 早退**（0086 同款模式）：每次背包槽位同步不再无条件全槽位扫描统计（含 `getMaxStackSize` 组件查找），无监听器（老玩家常态）时整段跳过
- **0094 tickChildren SetTimePacket 惰性分配**：每世界每 tick 的时间同步共享包改为首用构造；无玩家世界与 19/20 的 tick 零分配
