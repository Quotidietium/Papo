## 区块包缓存 TTL 驱逐（0269 转 fix）

- 0241/0242 多观众区块包缓存（LevelChunk 序列化 payload + ChunkHolder
  共享包，每区块数十至数百 KB）原先随区块加载**终身驻留**；现在
  600 tick（30s）无发送即驱逐，`-Dpapo.chunkPacketCacheTtlTicks` 可调
  （≤0 禁用，复现旧驻留行为用于诊断对照）。
- 多玩家多区块加载浸泡实测（12 bot × 150s 径向行走 + 180s 驻留，4G 堆
  双 Full GC 后测，4.4k 加载区块）：驻留缓存 ~83MB（堆的 9%）归零，
  byte[] −46.6%；TTL=0 对照腿复原旧驻留行为（同二进制）。
  [报告](../report/perf/2026-10-09-memsoak-r5-batch141.md)
