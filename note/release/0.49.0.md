- 基线：Minecraft 1.21.11 / Paper 上游
- 产物：`paper-server/build/libs/Papo-1.21.11-0.49.0.jar`
- 红线保持：默认行为等价、线上字节恒等、API 零变更、游戏版本红线 1.21.11 不变
- **游戏版本红线：始终保持 Minecraft 1.21.11**
- 性质：**多玩家网络稳定——join 玩家信息广播 memo**（批次 75，join 突发域收尾）

## 新增优化（0246）

### join 玩家信息广播双 memo + unlisted 变体提出
每次 join，同一 `ClientboundPlayerInfoUpdatePacket` 实例（新玩家条目：UUID + profile + 皮肤签名
~0.5-1.5KB，超压缩阈值）发给每个在线玩家——此前每连接各自编码 + DEFLATE 相同字节；unlisted
变体更在循环内对每个接收者重复构造同参数包。现两站点 arm 编码+压缩双 memo，unlisted 构造惰性
提出循环外。

### 同批否定结论（留档）
- 入站解压域无优化点（CompressionDecoder 两路径均按声明大小精确分配）。
- UPDATE_LATENCY 广播不可共享（canSee 视角 per-target）；UPDATE_HAT/GAME_MODE 小包不压缩。
- join 域剩余均 per-player 内容或红线外——**join 冗余面封闭**。
