# Papo 0.19.0 发布说明

- 基线：Minecraft 1.21.11 / Paper 上游（分支 ver/1.21.11）
- 产物：`paper-server/build/libs/Papo-1.21.11-0.19.0.jar`
- 红线保持：行为等价（全部改动经逐分支/逐位/语义等价论证），完整 test 套件 + applyPatches 全绿（1098 patches：sources 918 + features 174 + resources 6）
- **游戏版本红线：始终保持 Minecraft 1.21.11**

## 新增优化（0172–0174，共 3 个补丁，弹射物专题续）

- **0172 钓鱼浮标开阔水域判定命令式重写**：4 区域流式折叠（每判定约 500 次不可变 BlockPos 分配 + 流/Spliterator/方法引用）→ 单 scratch + 三重循环，INVALID 吸收早退（**3.72×**，CI 不重叠；offset 折入边界 int 逐位一致、访问序与 betweenClosedStream 行主序一致、组合子序无关早退保值）
- **0173 烟花火箭 tick 两分支 Vec3 中间量消除**：Elytra 助推 `dm.add(expr)` 与自由飞行 `multiply(d2,1.0,d2).add(0,0.04,0)` 逐分量内联（setDeltaMovement(Vec3) 纯委托、FP 链逐字、+0.0 项保留；30 组合矩阵逐位自检）
- **0174 火球 tick Vec3 消除**：applyInertia 四中间 Vec3 内联（保留 normalize 的 `1.0E-5F` 阈值分支，阈值路径 ZERO.scale(power) 与内联逐位一致）+ MISS 路径 position().add() 逐分量 setPos（rotateTowardsMovement 只改朝向不移动实体；阈值边界矩阵逐位自检）
