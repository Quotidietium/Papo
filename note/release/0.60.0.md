- 基线：Minecraft 1.21.11 / Paper 上游
- 产物：`paper-server/build/libs/Papo-1.21.11-0.60.0.jar`
- 红线保持：默认行为等价、API 零变更、游戏版本红线 1.21.11 不变
- 性质：**多核调度⑭——tick 相位分解探针**（批次 98，勘察/基建轮；默认行为零变化）

## 新增（批次 98）

### PapoTickProfile 相位分解探针（诊断基建，默认关）
`-Dpapo.tickProfile=1` 时在既有相位基础上新增四组细分与一项窗口计数，用于归因
批次 97 发现的聚堆规模下 connection 相位超线性（≈N^1.6-2）：

- `chunkMap.tracker.maintain` / `chunkMap.tracker.sendChanges`：实体追踪器的
  viewer 维护与广播循环分离计时；
- `conn.flushQueue` / `conn.listenerTick`：连接 tick 的出站队列排水与监听器 tick
  分离计时；
- `server.taskDrain`：每 tick 任务排水（含入站包处理）桥接进窗口报告；
- 窗口头新增 `gcMs=`：GC 窗口耗时计数（分辨 GC 压力贡献）。

关闭时每边界仍只有一次静态布尔检查，默认行为与 0.59.0 完全一致。

（U+FFFD）——批次 97 交付，随本版归档。
