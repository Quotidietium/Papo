# Papo 0.61.0 发布说明

- 基线：Minecraft 1.21.11 / Paper 上游
- 产物：`paper-server/build/libs/Papo-1.21.11-0.61.0.jar`
- 红线保持：默认行为等价（含 gamerule/配置边界：maxEntityCollisions、maxEntityCramming
  任意取值下 push 序列/挤压伤害判定/随机序列消耗逐位一致）、API 零变更、游戏版本红线不变
- 性质：**多核调度⑮——聚堆密度超线性面消除**（批次 99）

## 优化（批次 99）

### 实体推挤扫描有界化
大量实体/玩家聚集（出生点、活动服、小游戏服）时，`LivingEntity.pushEntities` 每实体
全量枚举 AABB 内重叠者，成本随局部密度线性放大（160 聚堆实测 listenerTick 相位
密度超线性 4.35×@1.33×人数）。本版改为双目标早停：推挤循环最多消费前
`max-entity-collisions` 个（fill 序），挤压判定只需两个布尔——扫描在这两个需求满足
即停，聚堆段 O(局部密度) → O(max(推挤上限, 挤压阈值))。

- 等价性：20,000 组随机配置对拍（推挤序列/挤压布尔/随机消耗奇偶）全 PASS + 机制证明；
- 性能：密度模型 JMH 5.1×；真实 160 并发聚堆 listenerTick −32%（7998→5461us/tick），
  推挤全成本 160 人合计 135us；分散常规服务器零变化（早停几乎不触发）。
