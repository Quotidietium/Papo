# 0.114.0（批次 206，2026-10-26）

插件兼容性修复轮：对 0.81.0-0.113.0 性能战役补丁（0267-0301，从未经过对抗兼容审计）做四簇并行深审 + 直提交面/品牌面自查，修复 13 项确认缺陷。红线回归 Paper 1.21.11 基线。

## 修复（补丁 0302-0308 + 直提交 + 构建清单）

1. **服务端 brand 恢复 Paper**（构建清单）：`Brand-Name: Papo` 经 `Bukkit.getName()`/`getServerModName()`（client brand payload）外泄，所有以 brand 字符串门控 Paper 特性的插件误判；Papo 身份改由 `Papo-Version` 属性 + `ServerBuildInfo.papoVersion()` 呈现。
2. **共享包/管线纯净门（0302）**：区块包缓存与共享实例、join 包缓存、pairing 扫描共享、编码/压缩 memo 只服务"纯 vanilla 管线"连接（fail-closed：出现任何非原生 handler 即回退 vanilla 逐连接构造）——ProtocolLib/PacketEvents 类按玩家改包不再被回滚或跨观众污染；压缩 memo 增加未压缩字节内容哈希校验（回放必内容命中）；player-info 包彻底不 memo（displayName 走 per-locale 渲染编解码，memo 会冻结首位观众 locale——即 R2/R3 被抛弃修复 0268 的缺陷本体）。
3. **区块方块实体活 map 契约（0303）**：`ChunkAccess.blockEntities` 恢复 `public final` 恒非 null（vanilla 同构造器，容量保持以钉迭代序）；`getBlockEntities()` 恒返回活 map——NMS 插件对空区块的直读直写不再 NPE/UOE。
4. **懒物品列表 null 契约（0304）**：`PapoLazyItemsList.set` 恢复 `Objects.requireNonNull`（vanilla NPE 快速失败，不再静默存 null 远处爆炸）。
5. **anti-xray 泄漏与 NBT 别名（0305）**：带 presetValues 的节不再 canonical 化为无 preset 共享实例（engine-mode 2/3 下 uniform 节明文出网且物化后永久失去混淆）；`PAP0_LONG_ARRAY` 解码快路恢复隔离拷贝（解码容器不再与 LongArrayTag 共享底层 long[]）。
6. **结构模板兼容（0306+直提交）**：恢复 `TemplateStructurePiece.template` protected final 字段（NMS 二进制兼容）；Bukkit `getStructure`/`getStructures` 递出活实例即防 TTL 逐出（vanilla 恒同实例，未保存内存改动存活）。
7. **拾取动画包（0307）**：`canPickupItems=false` 零监听快路不再多发 take 动画包（`setCancelled(true)` 隐式置 `flyAtPlayer=false`，批次 135 误读）。
8. **放置走查锁步门（0308）**：`papoForEachPosition` 仅在 getPositions/forEachPosition 同类声明锁步时走循环孪生，插件"只覆盖 getPositions"的形态仍由其覆盖驱动（不再被静默绕过）。
9. **PDC 微修（直提交）**：`set` 判空异常文案恢复上游原文；`adapterContext` 字段保持 protected。
