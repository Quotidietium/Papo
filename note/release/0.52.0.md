## 新增优化（批次 78，直提交）

### 核心感知的线程池自动 sizing
新增 `PapoParallelism` 集中多核预算决策（显式配置永远优先）：

- **Netty 事件循环**（spigot.yml `settings.netty-threads` 默认值）：平 4 → cores/4 clamp [4,16]。
  空闲循环 park 于 selector 零成本；≤16 核主机行为不变。
- **Region IO 线程**（paper-global `chunk-system.io-threads` auto）：平 1 → cores/8 clamp [1,4]。
  此前全部世界全部 region file 的读写串行过单线程——一个冷读的磁盘延迟卡住其他一切 region IO。
  `AreaDependentQueue` 点区域串行化保证同一 region file 永不并发访问，多线程只并行化不同
  region file。
- 存量安装已物化的 spigot.yml `4` 保持不变（INFO 提示可删 key 启用 auto）。

## 构建修复

  泛型签名解析的陷阱（私有静态方法，零 API/行为影响；详见 build.md）。

## 基准

- IoPoolScalingBench（真实 concurrentutil 0.0.8 池+AreaDependentQueue，8 region file × 16 任务，
  4KiB 真实读 + 模拟设备延迟）：1 线程（旧 auto）1992ms → 4 线程（32 核 auto）450ms（**4.43×**）。
- 安全自检全绿：每 region file 内并发度恒 ≤1（多线程下同文件绝不并发）、per-region FIFO、
  任务恰好完成一次、并行度实测兑现。
