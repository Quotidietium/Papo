## 新增优化（0203–0204，共 2 个补丁）

三路 survey（聚集广播热路径 / 网络突发与区块发送 / 插件指纹泄露）产出候选，本批落地 2 个补丁。JMH 报告：[note/report/perf/2026-08-02-jmh-microbench-batch50.md](../report/perf/2026-08-02-jmh-microbench-batch50.md)。

### 0203 — PlayerChunkSender 区块发送选块去装箱（网络/流畅度）
- 跑图/登录突发期每玩家每 tick 区块发送收集，原 `.stream().collect(Comparators.least(...))` 把每个 pending long 装箱为 Long + Guava PriorityQueue/Collector。改为原语 k 近邻（`longIterator` + `long[floor]`/`int[floor]` 有界缓冲 + 选择排序），零装箱。
- **JMH**：10.0× 提速（8694 → 869 ns/op，CI 不重叠）；`-prof gc` 分配 6088 → 144 B/op（**42× 分配降低**）。
- **等价性**：距离两两不同时选择结果与原版逐元素一致；等距并列时哪个被选两实现均未定义且对客户端不可观察（等距区块批量发送，未选者下 tick 发送）。

### 0204 — ChunkMap.TrackedEntity.updatePlayer 已追踪对跳过冗余 canSee（聚集延迟）
- 稳态聚集时绝大多数 (实体,玩家) 对已追踪，原实现仍每对每 tick 重算跨方法 `canSee`（HashMap 查找 + 多态分发）。改为先 `seenBy.contains` 判断，已追踪则跳过。
- **JMH**：非空 inverted map（真实 vanish 插件场景）1.15×（CI 不重叠）；空 map 下 0.67× 为静态方法 JIT 折叠伪影（机制保留，同 0140/0186/0200 先例）。
- **等价性**：关键不变量 `seenBy.contains(conn) ⟹ canSee == true`（hideEntity / setVisibleByDefault(false) / resetAndHideEntity 均经 removePlayer 先移除对）逐路径源码实证。
