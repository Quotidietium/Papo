## 新增优化（0175–0178，共 4 个补丁，移动/战斗 Vec3 专题）

- **0175 Entity.getInputVector 内联**：`(d>1.0 ? normalize() : relative).scale(scaler)` 中间 Vec3 逐分量内联——每个移动中的生物/玩家每 tick 经 travel→moveRelative 触达（lengthSqr 与 normalize 求和逐字相同、d>1.0 时阈值分支不可达、220 组合矩阵逐位自检；签名与返回语义不变）
- **0176 LivingEntity.knockback 内联**：`new Vec3(x,0,z).normalize().scale(strength)` 三中间 Vec3 → 仅取 x/z 分量（while 循环 RNG 序列不动、阈值分支证不可达、vec3.y 从不被读；贴阈值/-0.0/Inf 矩阵逐位自检）
- **0177 格挡视角向量内联×2**（applyItemBlocking/resolveBlockedDamage）：position/subtract/水平化/normalize 四中间 Vec3 消除（**1.09×**，CI 不重叠；normalize 阈值保留，被丢弃 ±0.0 y 项的唯一零号分歧被 Math.acos 抹除，200 组合 acos 输出逐位自检）
- **0178 批次 43 注释勘正**（零行为变更）：setDeltaMovement(Vec3) 为 isFinite 守卫赋值非"纯委托"；中间量计数修正
