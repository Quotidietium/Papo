## 新增优化（0190–0192，共 3 个补丁，实体查询 scratch list 机制）

批次 46 survey 移入的 3 项 scratch-list 候选落地。JMH 真实规模实测 **1.08×–2.26×（CI 不重叠）**：

- **0190 Level getEntities fill 重载 + pushEntities scratch list**（**2.26×**）：每个 pushable 实体每 tick 省 ArrayList + 扩容拷贝；重入论证——hurtServer/doPush 回调无 API 路径重入同实体 pushEntities
- **0191 Mob.aiStep looting scratch list**（**1.08×**）：每个可拾取生物每 tick 省 ArrayList（复用上游已有 EntityTypeTest fill 重载）
- **0192 NearestAttackableTargetGoal.findTarget scratch list**（**1.21×**）：每目标扫描省 ArrayList；无子类覆写 findTarget（11 子类全库 grep 实证），getNearestEntity 仅迭代不保留

## 判例记录（小规模 JIT 伪影证伪法）

- 小规模复刻（盒内 ≤10 实体）稳定出现 after 慢约 2× 的反转；经 gc 探针（before 80 B/op → after 0.001 B/op）+ 成本模型（after 工作量为 before 严格子集，反向差物理不可能）+ 规模翻转三中证伪为 JIT 伪影，机制保留（0140/0157 先例）。与 0100/0181 撤销判例的区别：那两项回退有真实物理机制，本项没有。方法论已记入 build.md（"工作量严格子集却更慢"时先 gc 探针再谈撤销）
