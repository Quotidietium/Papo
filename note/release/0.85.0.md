## 常量区块节的容器状态坍缩（单值 Data 共享）

- 87% 的区块节是常量节（地表以上全空气、均匀生物群系）：576k 个单值容器各持有
  Data + SingleValuePalette + palette 缓存数组 ≈ 80B，仅取决于 (strategy, 值)。
  现全部共享为每 (strategy, 注册表 id) 一个规范 Data；负载 ZeroBitStorage 批145
  已共享，至此单值容器的四层状态全部坍缩。
- 安全契约：共享值以注册表 id 为键（规范实例即注册表驻留实例，引用比较行为
  逐位不变）；发布后的共享 Data 永不结构突变（增长换属主容器 data、就地写仅
  引用幂等、就地重写的 buffer-read 路径守卫私有化，服务端不走该路径）；缓存挂
  Strategy 实例随 level 卸载回收，容量上界 = 注册表大小。
- 浸泡两腿实测（12 bot、6,072 vs 6,114 区块配对，门全绿）：堆 865.3 → 831.6MB
  （**−3.9%**）；转储普查归因闭合：单值 palette 缓存数组 **569,100 → 11 个**，
  多值缓存逐档不变，PalettedContainer 实例数不变（语义零变化）。
