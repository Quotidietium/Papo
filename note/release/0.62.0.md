# Papo 0.62.0 发布说明

- 基线：Minecraft 1.21.11 / Paper 上游
- 产物：`paper-server/build/libs/Papo-1.21.11-0.62.0.jar`
- 红线保持：默认行为等价（扫描谓词/顺序/快照语义逐字一致）、API 零变更、游戏版本红线不变
- 性质：**多核调度⑯——每玩家每 tick 分配消除**（批次 100）

## 优化（批次 100）

### 玩家 aiStep 接触扫描 scratch 化
`Player.aiStep` 每 tick 为附近实体接触检查（物品拾取、XP 收集等 `playerTouch` 派发的
上游）分配一个新列表——大量玩家聚集时每 tick 数千次分配。改为每玩家复用 scratch
列表，谓词与迭代语义与原路径逐字一致。分配归零；对密集聚集服务器降低 GC 压力。
