# 0.90.0（批次 157 / R17：静态形状表收割）

内存占用继续下降：配对浸泡（12 玩家、视距 10，区块配对 ±1% 门内）**−14.2MB
（−2.12%，保守口径：优化侧多载 0.60% 区块仍胜）**，每区块全量 113.3→110.3KB。
与 0.88.0 相比 shape 族累计坍缩 **−94%**（AABB 345,808→20,333 等，转储 census
逐位归因）。

## 变更

- `Block.getShapeForEachState` 两个重载：每状态形状表（楼梯/墙/栅栏/挂牌等，
  引导期一次性建造）收集值经 `PapoShapeCache.papoCanonical` 规范共享——等
  几何跨块类型坍缩为单实例。建造点即长寿命持有点，瞬态形状从不流经，表
  大小仍被注册表不同几何数严格上界。

## 兼容性

- 几何逐位不变；仅实例同一性变化；Bukkit `getShape/getCollisionShape` 包装
  逐调用新建，API 语义不变。
- 验证：`:paper-server:test` 全绿（新增跨类型共享判别 2 项）；applyPatches
  重放 EXIT=0；check_patch_counts ALL OK；compileJava --rerun-tasks 成功。

## 升级

替换 `Papo-1.21.11-0.90.0.jar` 即可，无配置与盘格式变化。
