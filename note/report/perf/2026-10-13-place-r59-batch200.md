## 0. 选轴事实核查（R38 判例：指令候选先事实核查）

验证器候选三核查：①区块卸载窗分配轴——R28-R32 只测加载轴，卸载窗理论上是
对偶面；但 R12 加载→卸载→重载周期 LongRunGrowth 已覆盖卸载路径的存活轴，
且卸载期分配主体=保存族（R43 已成像维持）；②TPS 饱和压力轴——分配普查
依赖 1ms 采样地板，饱和窗的自缩放混杂（R40 判例弧形直对自缩放判负）先行
封死解释力；③**方块放置轴**——R48 挖掘风暴（PLAYER_ACTION 破坏链）的对偶
right-click 放方块链（SET_CREATIVE_MODE_SLOT+USE_ITEM_ON→BlockItem.place/
canPlace 碰撞/BlockPlaceEvent 事件机器/状态广播）在 R48 报告**零放置提及**，

事件机器（R36 判例强两档族）与 Papo 自有补丁热路径（handleUseItemOn 的
papoHasListeners 标量距离检查零监听快路恰在此链上）。

  insideBorder），与 1.21.2+ move 尾单字节打包同族线格式演化；

## 3. 判定：四支柱判负闭合（第十六域）

**放置链成像**（B 全栈扫描，A=0 差分纯净）：77 事件/~77.5MB 采样权重 =
**窗 raw 权重 0.155%**；逐面计数最大 10（Arrays.copyOf），**全部单项 <
20 立信阈**——链总 77 ≥20 但分解后无单体机械面。面分解全归已知族：
- ZeroCollidingReferenceStateTable$MapView 族 ×15+（getBlockstate 属性查询
  陪跑）=Moonrise 上游架构（R42/R54 判例）；
- 事件机器基建（PriorityQueue/HashMap.newNode/ConcurrentHashMap.putVal/
  StringBuilder/StateHolder.toString）=R36 判例强两档（语义不可去）；
- Arrays.copyOf/copyOfRangeByte=数据面增长（多轮判负维持）；
- **RegistryFriendlyByteBuf.lambda$decorator$0 ← StreamCodec$5.encode
  +80（580→660）**=放置方块更新广播=R44 维持清单**同一张脸**（mapStream
  适配器每出站包一包装，判负维持复现）；
- updateNeighbourShapes ×21 in-stack=BlockPos.relative 邻域更新族=R58
  判例维持（结果对象/语义本体混合）。

**四支柱**：①量级——0.155% 窗重、每放置 ~67KB（含广播+邻域更新全链），
低于收割门槛两个数量级；②恒等可证——无 census 显著单体面；唯一同族候选
BlockCanBuildEvent 零监听下**无条件** callEvent（BlockItem.canPlace 源码，
与 papo 0254 族零监听快路同族）在 census 不可测（~KB×每次≈MB 级/窗，低于
采样地板三个数量级）→R24 三门槛第一腿不成立，**入维持代价面备忘**（与
PacketEncoder memo 同列）；③上游——Moonrise 状态表族=R42/R54；④相位/环境
——B−A 环境重排（ItemEntity 碰撞分支 ±242/−246 净零、NaturalSpawner −88、
spark +52）带内噪声（R56 判例）；heap +5.0%=放置方块数据面（1,147 石头+
区块 section palette 重排，R57 数据面画像同型）。**收割面回流零**
（papoVisitCorners 308/317 等量在场、travel-dedupe/papoCalculateTargetStrength
不在场=零通道零回归）。存活侧双腿干净（13/8 事件全 spark 自观测族）。

**判定：四支柱判负闭合，第十六域（方块放置轴）终态**。分配普查十六域
（流送/盘载/驻留/实体+保存/维度/红石/长时浸泡/极端密度/高并发/复合/放置）
全覆盖终态维持。

## 4. 判例（build.md 同步）

1. **包 ID 权威提取**：bot 新包 ID 唯一正确路径=GameProtocols.java
   SERVERBOUND_TEMPLATE 注册表定义序提取（`(\w+PacketTypes)\.(\w+)` 逐
   addPacket）；锚点线性外推（+10 偏移）失效因 common/ping/cookie 包在
   特定位置穿插（0x35=SET_COMMAND_BLOCK 非 CREATIVE_SLOT、0x3d=
   TELEPORT_TO_ENTITY 非 USE_ITEM_ON）。服务器日志踢因（包名+extra 字节数）
   是协议错位实锚。**通式：新包 ID 必须注册表提取+单 bot 隔离验证器实证
   （PlaceVerify 三探针：Inventory/目标格/支撑格），不得锚点外推**——与
   R48「extraction regex 漏 common 前缀移位 4」同源陷阱两连踩。
2. **BlockHitResult 双布尔**：1.21.11 writeBlockHitResult 尾
   isInside+isWorldBorderHit 两布尔（旧版单 insideBorder）——与 1.21.2+
   move 尾单字节打包同族：线格式逐版本演化，载荷长度差一字节即解码踢。
3. **replaceClicked 语义**：BlockPlaceContext 构造器
   `replaceClicked=getBlockState(点击格).canBeReplaced`——点击格=空气时
   getClickedPos() 返回点击格自身（非 relative(face) 外贴格）。放置探针
   必须查支撑格；查外贴格恒零命中（本腿 B 探针③失败真因，放置真实发生）。
4. **世界直存地面真值**（WorldProbe）：保存世界目录重开+forceload 加载+
   execute if block=最强放置证据（R57 两波制复用+R48 未加载静默假规避）；
   R58 复合门判例扩展：**探针坐标语义错误≠负载未发生**——bot 侧计数+
   特征帧+世界直存三源复合定谳。
5. **会话恢复杀 shell 判例（R44 扩展）**：编排 shell 死而 java 孤儿活=
   JFR 永不启动（JFR.start 是 shell 侧 loadWarmed 锚后 jcmd）——数据必然
   不完整，整腿重跑；孤儿先杀再重跑。**门/设计一致性自查**：门变量与
   harness 探针条件必须对照审查（本轮 air≥3 无条件门 vs 探针② place==0
   条件=B 腿必假失败，腿前自查拦下）。
6. **门阈值按候选池校准**：places≥1800 预估无据（真实候选池 d2≤25 表面
   格筛后 ~95/bot×12=1,140）；门阈=池真值−5% 余量（1080）。预估阈值先跑
   一腿实测池再定门，或首腿后校准并记录。
7. **采样地板下的链级成像**：小风暴（10³ 次级）单链事件在 1ms 采样地板
   下成链级样本（77 事件全栈 in-stack 可见）但 top-40 聚合不可见——链级
   显著性判定须用全栈符号扫描（jfr print+grep）而非聚合 top-N。
