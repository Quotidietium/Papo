## 1. 方法与形态失败修复（本批核心工程判例）

**v1 形态失败**：直接 `execute in <dim> run fill ...` 触发生成——**Paper 异步区块
体系对未加载位置直接拒绝**（服务器日志 24×"That position is not loaded"，无主线程
同步加载路径）；磁盘增量仅为末批 forceload 2 区块邻域。JFR 窗内维度生成量远低于
设计意图=形态失败，按 R44 判例整腿重跑不缝合。

**v2 两波制**（CompositeCensus dims 参数，bot 零改动）：
- 波①（marker+25s，JFR 已激活）：每 bot 每维度 `forceload add 3×3 区块区间`
  ×24 处=**跨维度异步生成负载主体**（下界/末地远端独立 region，noise+carver+
  特征+光照全管线）；
- 波②（marker+130s，生成完成）：同位置 fill 11×15×11——此时区块已加载，
  **fill 24/24 生效**（服务器日志 "Successfully filled"×24）；
- 探针（marker+150s）：`execute in ... execute if block ... run say DIM-N-OK/
  DIM-E-OK` **双中**=生成+放置生效铁证；探针后 `forceload remove all` 清票面；
- measure（digMs=360s 推导至 marker+312s），JFR 300s 双事件集。

门变量 filled（fill 回显计数）捕获位置缺陷（回显时点无 probe 读窗）——**服务器
日志复核 24/24+forceload 24/24+零拒绝+dimN/dimE 探针**替代门（R55 事实核查判例的
日志复核变体），B 腿数据定谳有效。

## 5. 判例

1. **Paper fill 对未加载位置直接拒绝**（"That position is not loaded"×N 静默——
   异步区块体系无主线程同步加载）：**跨维度负载触发两波制通式**=波① forceload
   触发异步生成→波② fill 生效；直接 fill 未加载区域=形态失败。
2. **门变量测量位置是数据有效性的一部分**：重要回显发生在 probe 读窗外时门变量
   恒 0——harness 须在命令发出时点带读窗，或以服务器日志复核替代（本批 fill
   24/24 日志复核，R55 事实核查判例的日志变体）。
3. **形态失败按 R44 判例整腿重跑**：数据完整（exit 0/logErrors 0）但负载未达
   设计量（JFR 窗内生成不足）=不缝合不降格判读，修复后整腿重跑。
4. **RNG 红线的维度轴再确认**：LegacyRandomSource per-feature 工厂在跨维度生成
   首像中霸榜 B 独有面——绝对红线与维度无关（R24 判例的无维度例外性）。
