# R53 复合负载收割面版本配对终验（0.107 vs 0.110）→ 坍缩验证通过（批次194）

- **轮次**：R53（批次 194）｜分支 perf/memory-r5｜版本保持 **0.110.0**（无代码变更）
- **轴**：收割面终验扩展——R51 在高并发流送形态做过 0.107 vs 0.110 坍缩终验；R52 复合负载只做了同二进制发现轮。本轮把**复合形态**（0298 收割面的原始高压形态：3.6k 站立实体+drain+~7.2k 挖/窗同窗叠加）下的跨版本坍缩补上。
- **结论**：**坍缩验证通过**——R47 收割簇 **1,056 trips → 0**（−100%，~966MB 权重蒸发）；替代面如期出现（papoVisitCorners 0→110）；零 0.110 独有新面；其余面全落自观测/网络/生成族噪声带。**配对恰为单收割隔离窗**：0.107→0.110 间唯一代码变更就是 0298（R48-R52 五轮均无代码变更）。

## 1. 动机与设计（R51 高并发终验的复合负载对偶）

R52 证明了复合叠加线性（同二进制 0.110 A vs B），但收割面坍缩的跨版本验证只在高并发流送形态（R51：betweenCorners 9→0——流送窗里移动实体只有 12 个 bot）做过。0298 收割面的原始高压形态是物品实体旋涡（R47 立项时 929 trips/931MB@1,200 items/bot），复合负载=该形态+挖掘+驻立叠加。本轮 `alloccensus-r53cmppair.sh`：双 cmp=1 腿（A=0.107.0、B=0.110.0），CompositeCensus 零改动复用，JFR 60s@1ms 锚 loadWarmed=marker+12s，双腿同复合正证据门+端口独占门+工作量等价锚（digsTotal 同量级）。

协议风险前置：同 harness 同形态已在 R52 探针轮+正式腿三次全绿——本轮无新协议面。

## 2. 首轮 B 腿环境瞬态与整腿重跑（判例）

首轮 B 腿（01:09 起）时间线本体全绿（探针+measure 完成）后单 bot 抛 `SocketException`（本机软件中止连接）→ exit 1=gate 不完整。**临时目录 server latest.log 定位：4 个 bot（CSB09/11/04/08）在 8 秒内连环 keepalive timeout 踢出（01:14:02-01:14:10）=服务器侧停摆签名**（所有在途 keepalive 同时到期，非单 bot 协议失败；R50 端口互踩判例的"中止连接"签名但无第二个 harness——本机环境瞬态停摆）。JFR 窗尾部覆盖踢出期+rc≠0 → **按 R44 判例整腿重跑不缝合**；重跑双门全绿（digs 9,483/9,511）→ 瞬态定谳（R48/R51 同序复跑判例）。

## 5. 零回归与零新面

增加面（B−A ≥20）全数归因：自观测族（InetSocketAddress +237·StringBuilder +132·Inet4Address +87·ThreadImpl +51——随包数缩放，R41 剥离判例）；网络（slice +306·RegistryFriendlyByteBuf +141·copyOfRangeByte +124——tracker/ack 包量）；spark 采样器（+56/+52/+46/+35——随分配活动量缩放）；生成族（spawnForChunk +105·getRandomPosWithin +28·getMobsAt +29——RNG 红线域相位噪声）；`papoVisitCorners` +110=收割替代面本体。物理族混号（Vec3.scale −172 而 makeBoundingBox +54/inflate +54）=窗相组成漂移带内。**无任何 0.110 独有面**；簇坍缩 −100% 远超任何相位带。

heap +6.3%：与存活物品 +3.7%、生成活动 +23% 同向=窗相组成缩放（R39 判例）；0298 的驻留效应已在 R47 同组成配对（14,400 items 恒等）定谳 −3.6%，本配对不重复该主张。

## 6. 判例

1. **keepalive 连环踢出=服务器停摆签名**（区别于单 bot 协议失败）：多个 bot 在数秒内相继 keepalive timeout=所有在途 keepalive 同时到期=服务器侧 ~30s 停摆（GC/OS 调度/磁盘），单 bot 网络问题不会同时到期内多个不相干连接；诊断入口=临时目录 server latest.log（harness stdout 不含踢出行时）。gate 破坏 → R44 整腿重跑不缝合；重跑通过=环境瞬态定谳（R48/R51 同序复跑判例）。
2. **版本配对的收割批切分读法**：0.107→0.110 间唯一代码变更=0298，配对差分即该收割的净面——StepBasedCollector（R41 已入 0.106）两腿同在、betweenCorners 簇/LongOpenHashSet 全坍的切分线精确落在 0.110 收割边界上，为"配对差分=版本窗内变更净效应"提供直接演示。
